# Mon Chef V33 — NORMATIVE / HACCP COMPLIANCE ENGINE

## Нормативная политика
С 01.09.2026 для организаций общественного питания базовый действующий документ в модуле — **СанПиН 2.3/2.4.4282-26**. СанПиН 2.3/2.4.3590-20 сохранён только как историческая редакция.

Обязательные требования НПА/техрегламентов и добровольные методические ГОСТ разделены. ГОСТ не помечается как обязательный автоматически.

## Методическая база
- ТР ТС 021/2011 — обязательная безопасность пищевой продукции.
- СанПиН 2.3/2.4.4282-26 — действующие требования общепита с 01.09.2026.
- ГОСТ Р 51705.1-2001 — принципы ХАССП.
- ГОСТ Р ИСО 22000-2019 — система менеджмента безопасности пищевой продукции.
- ГОСТ Р 55889-2024 — рекомендации для индустрии питания по применению ГОСТ Р ИСО 22000-2019.
- ГОСТ 31984-2012 — общие требования к услугам общественного питания.

## Что добавлено
- нормативный реестр;
- реестр требований с юридическим статусом;
- evidence/check records;
- readiness по обязательным требованиям;
- версия нормативной базы;
- разделение mandatory / guidance;
- отдельный экран `?normative=1&token=...`.

## Принцип
Mon Chef не должен объявлять предприятие «соответствующим Роспотребнадзору» только потому, что заполнены поля. Система показывает документированные доказательства выполнения требований и незакрытые области; фактическое соблюдение зависит от реальной работы предприятия.
