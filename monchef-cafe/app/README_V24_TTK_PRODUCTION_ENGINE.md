# Mon Chef V24 — TTK Production Engine

V24 добавляет исполнимую декомпозицию ТТК: блюдо -> полуфабрикаты -> полуфабрикаты следующего уровня -> сырьё.

## Что делает
- `getTTKProductionTree(code, qty, token)` — показывает дерево потребности конкретной ТТК.
- учитывает доступный остаток П/Ф из склада и не планирует производство того, что уже есть;
- `buildWeeklyTTKDependencyPlan(fromDate, token)` — строит зависимости по опубликованной/расчётной неделе;
- `publishWeeklyTTKDependencyPlan(fromDate, token)` — сохраняет задачи П/Ф в `Производственные_Зависимости_V24`.

V24 не списывает склад. Списание выполняется существующим V23/production core после фактического отбора и выпуска.

## UI
`?production=1&token=...` — производственный диспетчер.
