# Mon Chef V28 — Банкет: комплектация и фактическая выдача

## Цель
Замкнуть производственный цикл после V27: готовые партии -> комплектация банкета -> фактическая выдача.

## Что делает V28
- показывает состав банкета и плановое количество блюд;
- учитывает уже выданное;
- проверяет готовые партии через FEFO;
- не разрешает выдать больше плана;
- не разрешает выдачу при нехватке готовой продукции;
- при подтверждении списывает именно фактически выданное количество;
- фиксирует использованные BatchID;
- пишет аудит, FACT `BANQUET_ISSUE` и trace link партия -> банкет;
- повторное открытие экрана не создаёт повторное списание.

## Важно
V28 не вызывает `consumeEventReservations`: резерв сырья и выдача готового блюда — разные хозяйственные события. Сырьё списывается производством V27, готовая партия — при фактической выдаче банкету.

## Экран
`?fulfillment=1&token=...`

## Лист
`Выдача_V28`

## Проверка
1. Создать/выбрать тестовый банкет.
2. Выпустить готовую партию через V27.
3. Открыть V28.
4. Убедиться, что FEFO показывает партию.
5. Подтвердить выдачу.
6. Проверить остаток партии, `Выдача_V28`, Audit/FACT/Trace.
