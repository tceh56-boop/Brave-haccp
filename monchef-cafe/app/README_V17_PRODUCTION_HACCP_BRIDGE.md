# Mon Chef V17 — Production ↔ HACCP Bridge

V17 связывает производственный контур с автоматическим HACCP-контролем.

## Что добавлено

- `HACCP_ТТК_Контроли` — явные правила контроля для конкретной ТТК;
- `HACCP_Производственные_События` — журнал автоматических производственных событий;
- после завершения реального заказа производства с партией система может автоматически поставить:
  - бракераж;
  - контроль охлаждения через заданное количество минут;
  - контроль разогрева через заданное количество минут;
- контроль создаётся только для ТТК, для которой ответственное лицо явно включило соответствующее правило;
- фактические температуры система не придумывает;
- контроль привязан к `ProductionID`, `TTKID` и `BatchID`;
- цикл V17 можно запускать каждые 5 минут отдельным Apps Script trigger.

## Настройка

1. Выполнить `seedMonChefProductionHaccpRules()`.
2. Для каждой ТТК настроить `upsertProductionHaccpRule()`:
   - `coolingRequired=true`, `coolingMinutes=...` если требуется контроль охлаждения;
   - `reheatRequired=true`, `reheatMinutes=...` если требуется контроль разогрева;
   - `brakerageRequired=true` если нужен отдельный контроль бракеража.
3. Установить trigger `installMonChefProductionHaccpBridgeTrigger()`.

## Важный принцип

V17 не считает факт контроля выполненным из факта производства. Производство только создаёт **ожидаемую контрольную задачу**. Измерение/решение сотрудника остаётся фактическим событием HACCP.
