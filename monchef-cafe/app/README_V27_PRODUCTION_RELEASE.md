# Mon Chef V27 — Производственный выпуск

V27 добавляет единый экран исполнения производственных заданий и замыкает цепочку:

`план производства → запуск сменой → фактический выход → складская партия → этикетка → HACCP-контрольные задачи`.

## Что добавлено
- `Execution.html` — экран повара/производства: список заданий, запуск и завершение.
- `MonChef_V27_ProductionRelease.gs` — API и журнал исполнений `Выпуск_V27`.
- маршрут Web App: `?execution=1&token=...`.
- фактический выход вводится сотрудником; срок годности можно указать, он не рассчитывается произвольно.
- при завершении используется существующее `completeProduction()` и `_produceCore_()`; повторное завершение не списывает сырьё повторно.
- после выпуска создаётся этикетка партии и запускается обработчик HACCP-моста V17, который создаёт только задачи измерений/контролей по явно настроенным правилам ТТК.

## Установка
1. Загрузить все файлы пакета в один проект Google Apps Script (заменить `Code.gs`, добавить новые `.gs` и HTML-файл `Execution.html`).
2. Сохранить проект и выполнить обычную авторизацию/разрешения Apps Script.
3. Открыть Web App по адресу `.../exec?execution=1&token=ВАШ_ТОКЕН`.
4. У пользователя должна быть роль `kanban` (или соответствующая роль, допускаемая вашей текущей матрицей прав).

## Важные ограничения
- V27 — интеграционный слой поверх существующего производственного ядра, не отдельный параллельный механизм списания.
- Для автосоздания HACCP-задач у ТТК должны быть заведены правила в `HACCP_ТТК_Контроли` (V17). Без правила измерения не выдумываются.
- Срок годности задаётся из утверждённой ТТК/технологической документации или ответственным сотрудником; V27 не назначает нормативы самостоятельно.
- Текущая проверка синтаксиса не заменяет проверку на тестовой копии Google Sheets/Apps Script. Перед эксплуатацией прогнать тестовый выпуск с тестовыми остатками и проверить списание, партию, трассировку и задачи HACCP.
