# Mon Chef V41 — Дезсредства и санитария

## Зачем
Справочник дезсредств, режимов применения, рабочих растворов, контроля концентрации и санитарных задач.

## Важный принцип
Переданные пользователем строки импортируются как `IMPORTED_REFERENCE / REVIEW`. Они не являются автоматически утверждёнными режимами Mon Chef.

Для работы кухни средство должно пройти проверку:
- регистрация/разрешительные документы;
- инструкция конкретного производителя;
- разрешение на применение на объектах общественного питания;
- объект обработки;
- концентрация;
- экспозиция;
- способ обработки;
- необходимость смывания;
- срок годности рабочего раствора.

Роспотребнадзор указывает, что для общепита следует применять зарегистрированные средства, разрешённые для такого применения; режимы концентрации и экспозиции берутся из инструкции конкретного средства. Ёмкости с рабочими растворами должны иметь маркировку и срок годности раствора. См. официальные материалы Роспотребнадзора.

## Таблицы
- `Дезсредства_V41` — мастер средств;
- `Дезсредства_Режимы_V41` — режимы по объектам;
- `Дезсредства_Растворы_V41` — фактически приготовленные растворы;
- `Дезсредства_Задачи_V41` — задачи персонала;
- `Дезсредства_Факты_V41` — фактические проверки;
- `Дезсредства_Пробелы_V41` — незаполненные/неподтверждённые данные.
