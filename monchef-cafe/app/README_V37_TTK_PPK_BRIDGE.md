# Mon Chef V37 — TTK → PPK/HACCP Bridge

## Что изменилось
V37 строит документно-изолированную модель ППК/ХАССП из реального графа ТТК V36.

### Главное
- каждый ППК имеет собственный `DocumentID`;
- ТТК и зависимости П/Ф привязываются к конкретному ППК;
- технологические операции копируются из `ТТК_Технология_V36` в scoped-процессы;
- контрольные меры хранятся отдельно и тоже имеют `DocumentID`;
- отсутствующие анализы опасностей/контроли создаются как явные пробелы;
- система НЕ генерирует критические пределы, CCP/OPRP или нормативные значения из воздуха;
- активация запрещена при открытых структурных пробелах.

## Нормативная логика
V37 использует ТТК как технологический источник, но не считает их сами по себе доказательством выполнения HACCP. Процедуры HACCP, документирование контролируемых этапов, результаты контроля и прослеживаемость должны поддерживаться отдельно.
