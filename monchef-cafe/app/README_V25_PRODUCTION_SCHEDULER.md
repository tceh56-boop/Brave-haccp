# Mon Chef V25 — Production Scheduler

V25 добавляет обратное планирование производства от времени банкета.

## Цепочка
Банкет -> готовое блюдо -> П/Ф -> П/Ф -> отбор сырья.

Для каждого ТТК создаётся настраиваемый профиль времени в `Времена_ТТК_V25`:
- DurationMin — длительность операции;
- BufferMin — запас между зависимостями;
- PickMin — сколько времени нужно складу на отбор;
- Workshop — цех.

По умолчанию: блюдо 30 мин, П/Ф 60 мин, buffer 10 мин, отбор 30 мин. Эти значения являются только стартовыми и должны быть уточнены под реальную технологию.

`buildV25ProductionSchedule(fromDate, token)` — расчёт.
`publishV25ProductionSchedule(fromDate, token)` — публикация в `Производство_План_V25`.
`getV25Schedule(fromDate, token)` — чтение опубликованного плана.
`seedV25TTKTimes(token)` — создание недостающих профилей времени.

UI: `?scheduler=1&token=...`.

V25 не отмечает фактическое производство выполненным и не списывает склад. Фактические действия проходят через существующие контуры V23/V24/V7.
