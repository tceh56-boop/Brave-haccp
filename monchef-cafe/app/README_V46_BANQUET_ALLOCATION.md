# Mon Chef V46 — распределение одной производственной партии между банкетами

V46 замыкает связь агрегированного производства с банкетным исполнением.

## Модель

`Банкет 1 10 кг + Банкет 2 8 кг + Банкет 3 12 кг -> одна производственная задача 30 кг -> одна партия -> адресная выдача`

Есть три разных состояния:
- `PLANNED` — план распределения;
- `RESERVED` — количество закреплено за банкетом;
- `PARTIAL` — выдано частично;
- `ISSUED` — распределение выдано полностью.

Резерв не меняет склад. Фактическая выдача вызывает списание **конкретной партии выпуска**, пишет V28 выдачу, trace и FACT.

## Источник истины

- V25 — план и исходные распределения;
- V27 — фактический выпуск и партия;
- V46 — распределение выпуска по банкетам;
- V28 — банкетная выдача.

V46 не создаёт фиктивный выпуск и не дублирует списание сырья.
