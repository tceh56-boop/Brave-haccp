# Mon Chef V43 — Санитария + чек-листы

## Цель
Устранить двойной ввод между старым модулем чек-листов и V41/V42 санитарным контуром.

## Архитектура
`Чек-лист/расписание -> V43 task -> сотрудник -> FACT -> HACCP/журнал/alert`

Чек-лист является интерфейсом исполнения. Нормативный/операционный режим берётся из утверждённого V41.

## Новые листы
- `Санитария_Чеклисты_Связи_V43`
- `Санитария_Задачи_V43`
- `Санитария_ЧеклистФакты_V43`
- `Санитария_АвтоАлерты_V43`
- `Санитария_ЧеклистПробелы_V43`

## Автоматизация
`v43AutomationTick` запускает генерацию задач по расписанию чек-листов, проверку просрочек и V42 alerts.
`v43InstallAutomation()` ставит hourly trigger.

## Сопоставление
Пункт чек-листа сопоставляется с V41 по средству, концентрации и при возможности объекту. Если нет APPROVED + AllowedForCatering=YES режима, задача не создаётся; создаётся GAP.

## Выполнение
Сотрудник не заполняет журнал отдельно. Он выполняет пункт чек-листа. V43 пишет execution/fact и статус задачи. Отклонение создаёт alert.

## Важное
Автоматизация не придумывает концентрацию, экспозицию или результат. Фактические значения вводит сотрудник. Режимы из импортированного справочника V41 остаются REVIEW до проверки инструкции конкретного средства.
