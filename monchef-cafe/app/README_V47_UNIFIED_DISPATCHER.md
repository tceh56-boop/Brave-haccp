# Mon Chef V47 — Единый диспетчер производства банкетов

## Назначение
Единый операционный экран для цепочки:
`банкет → потребность → производство → production_id → партия → резерв → выдача → остаток/дефицит`.

## Источники истины
- V25 — график/план производства и распределение по банкетам.
- V44 — единая задача.
- V45 — связь задачи с реальным `production_id` и фактический статус производства.
- V27 — фактический запуск/выпуск производства.
- V46 — резерв и адресная выдача партии на банкет.

V47 не создаёт отдельного склада, выпуска или списания.

## Автоматическое обновление
`v47RefreshDispatcher()` последовательно:
1. синхронизирует задачи V25 → V44;
2. автоматически связывает производственные задачи с `production_id` через V45;
3. переносит распределение V25 в V46 без дублей;
4. обновляет статусы задач по фактическому производству;
5. строит диспетчерскую сводку.

## Экран
`?dispatcher=1&token=...`

Показывает:
- количество банкетов и производств;
- план/резерв/выдачу;
- нераспределённый выпуск;
- дефицит;
- строки по каждому банкету;
- детализацию конкретного банкета.

## Правило факта
Нажатие обновления не списывает сырьё и не создаёт выпуск. Факт производства создаётся производственным ядром. Выдача списывает конкретную партию через V46.
