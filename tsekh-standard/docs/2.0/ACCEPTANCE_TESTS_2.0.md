# ACCEPTANCE_TESTS_2.0 — приёмочные сценарии

Автотесты запускаются без сети на имитации Apps Script:

```bash
node tests/ts2_acceptance.test.js
node tests/license_flow.test.js
node tools/check_syntax.js app && node tools/check_syntax.js admin
```
