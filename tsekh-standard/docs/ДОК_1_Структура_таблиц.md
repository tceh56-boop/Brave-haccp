# ЦЕХ Стандарт — структура таблиц

Все данные хранятся в одной Google-таблице. Ниже — листы по разделам: назначение и колонки (по данным стенда на 12.10.2026). Листы создаются автоматически при первом использовании модуля.
Листы-доказательства защищаются кнопкой Настройки → «🔒 Защита журналов»; ручная правка в них пишется в Audit_Log.
