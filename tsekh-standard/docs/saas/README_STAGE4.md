# Установка патча Stage 4

Патч накопительный: содержит Stage 2/3 зависимости и изменённые файлы Stage 4. Это набор замен/добавлений к исходному пакету, а не полный исходный архив приложения.

1. Сделайте копии текущей таблицы клиента, Apps Script проекта и CONTROL.
2. Обновите CONTROL-файл `5_Админ-панель/Control.gs` из архива. Проверьте, что в карточке организации заполнено подтверждённое поле `Customer Drive Owner Email`.
3. В клиентском проекте замените перечисленные файлы из архива; добавьте новый `client_app/TS4_TenantIntegrity.gs`.
4. Для действующих клиентов обновите код через CONTROL, чтобы `TS_TENANT_CONFIG_` был повторно внедрён, включая `ownerEmail`. Не копируйте конфигурацию вручную между организациями.
5. Запустите авторизованную функцию `ts4TenantIntegrityCheck(token)` из интерфейса/временной диагностической обёртки. Не запускайте её как анонимный публичный endpoint.
6. Пройдите двухклиентский пилот из `REPORT_STAGE4.md`.

Не включайте массовое обновление действующих клиентов до успешного пилота. Если `ownerEmail` не подтверждён или клиентское хранилище недоступно, исправьте onboarding вручную через проверенный процесс; не подставляйте общий Drive поставщика.
