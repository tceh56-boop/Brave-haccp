Этап по документу «Итоговая структура системы прослеживаемости продуктов и экономики MonChef» (09.11.2026). Управленческий учёт: бухгалтерию и кассу не заменяет.

## Правила
- Каждая функция проходит шлюз (`zzz_MonChef_Gate.gs`); права — ДОК_2, раздел 12; функции × роли — ДОК_8.
- Записи — под `_withLock_`, с OperationID и `Audit_Log`. Повторный одинаковый вызов в течение 15 с не дублирует запись.
- В закрытый период запись не проводится — только корректировка следующим периодом, подтверждающий ≠ автор.
- Технический доступ не утверждает ППК и ТУ, не закрывает период, не отбирает пробы, не загружает протоколы и не решает судьбу партий.
- Ничего не подставляется за пользователя: нет цены — признак «нет цены», нет данных для раздела ППК — пометка, непонятное значение в протоколе — «экспертная оценка».

## Экраны
`?finance=1`, `?ppk=1`, `?tu=1`, `?labx=1`, `?org=1`, `?reports20=1` открывают главное окно на нужном экране.

## Подготовка листов
Листы создаются при первом открытии; вручную — `setupV64Economy`, `setupV65Ppk`, `setupV66Tu`. Колонки — ДОК_1.
