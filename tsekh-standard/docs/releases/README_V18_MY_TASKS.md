# Mon Chef V18 — «Мои задачи сегодня»

Единый рабочий слой для сотрудника. Не создаёт новый журнал и не дублирует факты.
Собирает существующие задачи HACCP и производства в одну очередь.

## Что делает
- получает текущего авторизованного сотрудника;
- собирает HACCP-контроли оборудования;
- собирает HACCP-контроли, созданные производственным событием;
- собирает задания производства;
- сортирует: просрочено → требуется сейчас → запланировано → выполнено;
- позволяет завершить HACCP-контроль через существующий `completeHaccpEquipmentTask`;
- позволяет завершить производство через существующий `completeProduction`;
- не подставляет фактические измерения;
- каждые 5 минут может обновлять очередь и напоминания.

## API
- `getMyOperationalTasks(date, token)`
- `completeMyOperationalTask(json, token)`
- `runMonChefMyTasksCycle(token)`
- `runMonChefMyTasksCycleSystem()`
- `installMonChefMyTasksTrigger(token)`

## Важный принцип
V18 является диспетчером, а не дополнительным источником истины. Факты продолжают записываться существующими контурами производства/HACCP/FACT.
