# Mon Chef V44 — Единый центр задач + производство банкетов

V44 превращает задачи в единый диспетчерский поток. Ручные задачи и автоматически рассчитанные задачи производства используют один реестр.

## Контур
`банкет → ТТК → график производства V25 → единая задача → сотрудник → фактический выпуск V27 → FACT/HACCP/трассировка`

### Добавлено
- `Задачи_Единый_V44` — единый реестр.
- `Задачи_Выполнение_V44` — выполнение задач.
- `Задачи_Источники_V44` — происхождение.
- `Задачи_Алерты_V44` — просрочки.
- `v44CreateTask()` — ручное создание через «+ Создать задачу».
- `v44SyncProductionTasks()` — импорт плановых задач из `Производство_План_V25`.
- Привязка к `BanquetID`, `TTKCode`, количеству, единице и цеху.
- Идемпотентная синхронизация: одна строка V25 не создаёт дубликаты задач.

## Важное разделение
Завершение диспетчерской задачи **не подменяет фактический выпуск**. Фактический выпуск остаётся в производственном ядре (`Производство` / V27), где происходят списание сырья, выпуск партии, себестоимость, трассировка и HACCP-события.

## Интерфейс
`?taskcenter=1&token=...`

В центре доступны:
1. `+ Создать задачу`;
2. привязка ручной задачи к банкету;
3. синхронизация производства банкетов;
4. общий список открытых задач;
5. запуск/завершение задачи;
6. контроль просрочек.

## Следующий шаг
Следующий слой — связать конкретную производственную задачу не только с планом V25, но и с конкретным `production_id` V27, чтобы кнопка «В работу» могла запускать фактическое производственное задание, а завершение — подтверждаться только фактом выпуска.
