# Mon Chef V22 — Storage / FEFO / Batch Labels

## Назначение
После подтверждённой приёмки партия получает:
1. реальный BatchID;
2. дату изготовления/срок годности/партию поставщика;
3. автоматическое предложение места хранения;
4. автоматическое размещение, если найдено активное правило;
5. FEFO-ключ;
6. возможность зарезервировать партию под производство;
7. печатную этикетку партии.

## Важное правило
Автоматизация не должна угадывать опасные условия хранения. Если правило отсутствует, `MANUAL_REQUIRED`: сотрудник выбирает место вручную.

## Овощи и фрукты
В справочнике есть зона `PRODUCE-01`. Правила можно расширять по типу продукта и ключевым словам. После приёмки овощей/фруктов система предлагает/назначает эту зону, а этикетка содержит BatchID, количество, изготовление, срок годности, партию поставщика и место.

## FEFO
FEFO сортирует партии по сроку годности. Активные резервы вычитаются из доступного количества, поэтому одна и та же партия не резервируется повторно сверх остатка.

## Маркировка
`Labels.html` получает данные из `Склад_Партии` и создаёт печатную этикетку. QR содержит код `MC-<BatchID>`; он идентифицирует партию, а не является юридической маркировкой товара.

## База продуктов
В пакет включён `ProductCatalog_V22.csv`, сформированный из загруженного XLSX. Импорт выполняется через `?catalog=1&token=...`. Данные попадают в `Продукты_V22`.

## Листы
- `Склад_Места_V22`
- `Склад_Правила_V22`
- `FEFO_Резервы_V22`
- `Этикетки_Партии_V22`
- `Продукты_V22`

## Маршруты
- `?storage=1&token=...` — склад / FEFO
- `?labels=1&token=...` — печать этикетки
- `?catalog=1&token=...` — импорт базы продуктов
