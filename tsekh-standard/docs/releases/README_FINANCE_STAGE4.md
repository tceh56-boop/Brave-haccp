# ЦЕХ Финансы и Экономика — этап 4: Labor Cost (ставка × часы + премии)

Решение 14.11.2026: ФОТ — управленческий Labor Cost, не расчёт заработной платы. Новый модуль: `app/MonChef_V74_Labor.gs`.

## Откуда часы и деньги

| Первичная запись | Лист | Как попадает в Labor Cost |
|---|---|---|
| Смена «Моя смена» (начало и конец) | `MonChef_Смены` (уже есть, V19) | закрытая смена: часы = конец − начало; в табель не копируется |
| Часы без смены | `ФОТ_Табель` (MANUAL) | если сотрудник не отмечает смену |
| Исправление часов смены или записи | `ФОТ_Табель` (SHIFT_FIX) | заменяет смену; прежняя запись — CANCELLED с причиной, новая ссылается на неё |
| Ставка в час сотрудника или роли с даты | `ФОТ_Ставки` | новая ставка закрывает прежнюю днём раньше; прошлое не переписывается |
| Премия / удержание | `ФОТ_Премии` | черновик → подтверждает другой сотрудник с правом `finance_close` |

Стоимость = часы × ставка на дату смены (своя ставка, иначе ставка роли) + подтверждённые премии − удержания.

## Защита

- Часы вручную на дату, где у сотрудника есть смена, — отказ (исправляется сама смена). Вторая запись за день — только с отметкой «вторая смена».
- Нет ставки → сумма 0 и признак «нет ставки» (сигнал в P&L), а не выдуманная ставка.
- Смена > 16 ч, незакрытая смена прошлых дней, премии без решения — в «Требует внимания».
- Записи, ставки и премии в закрытом финансовом периоде не принимаются. Исправление — только с причиной; автор не подтверждает свою премию. Всё — в аудит.

## Куда идёт

Строки этапа «Труд» в журнале V64 → реестр операций (SHIFT, TIMESHEET, BONUS) → дневные итоги (`labor`, `laborHours`, `laborBonus`, `laborNoRate`, колонки справа) → P&L:
«ФОТ (Labor Cost), всего» = по сменам и табелю + премии − удержания + расход «Фонд оплаты труда». Если ФОТ есть и в табеле, и в расходах — предупреждение о возможном дубле.
Сводка руководителя: labor cost и prime cost по фактическим часам, «Часы труда», «Выручка на час труда».

## Экран

«Экономика» → вкладка «ФОТ»: итоги, «Требует внимания», по сотрудникам, ставки, часы без смены, исправление часов, смены и табель, премии и удержания с подтверждением.
В разделе «Экономика» во вкладке «По дням» — ФОТ и часы.
