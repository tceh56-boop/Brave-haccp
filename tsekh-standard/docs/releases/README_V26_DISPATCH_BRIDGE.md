# Mon Chef V26 — Dispatch Bridge

Связывает недельный производственный план V25 с фактическим складом и FEFO.

Цепочка: банкет/ТТК → график производства → потребность в сырье → FEFO-остаток → дефицит → закупка → резерв партии.

V26 не списывает сырьё при расчёте и резервировании. Фактический расход подтверждается V23 при сканировании партии.

## Основные функции
- `buildV26Dispatch(fromDate, token)` — рассчитывает потребность и покрытие FEFO.
- `publishV26Dispatch(fromDate, token)` — сохраняет снимок диспетчерского плана.
- `reserveV26Ready(fromDate, token)` — резервирует только полностью покрытые позиции.
- `getV26Dispatch(fromDate, token)` — читает сохранённый план.

Экран: `?dispatch=1&token=...`
