# ЦЕХ Финансы и Экономика — этап 5: деньги (Cash Flow) и банковская выписка

Решения 14.11.2026: без кассовой интеграции, банковская выписка загружается файлом. Новый модуль: `app/MonChef_V75_Cash.gs`.

## Листы

| Лист | Что хранит |
|---|---|
| `ДС_Счета` | касса и расчётные счета: начальный остаток на дату |
| `ДС_Движения` | одно движение денег — одна запись: счёт, дата, поступление/выплата, сумма, статья ДДС, контрагент, ИНН, назначение, документ, источник (вручную / выписка), ключ содержания |
| `ДС_Импорт` | каждая загрузка выписки: файл, период, добавлено, повторов, в закрытом периоде, остатки из выписки |
| `ДС_Правила` | правила разнесения: ИНН или контрагент → статья |

## Загрузка выписки

- Форматы: обмен «1С — Клиент банка» (`kl_to_1c.txt`, Windows-1251 или UTF-8) и CSV из интернет-банка (Дата; Приход/Расход или Сумма со знаком; Контрагент; ИНН; Назначение; Номер).
- Счёт — по номеру из выписки; если его нет, заводится сам с остатком на начало из выписки.
- Без дублей: повторная или пересекающаяся выписка добавляет только новые операции.
- Сверка: остаток на конец по выписке сравнивается с расчётом.
- Операции закрытого финансового периода не загружаются (их число — в отчёте загрузки).

## Разнесение по статьям ДДС

Правило по ИНН → поставщик из справочника («Оплата поставщикам продуктов») → правило по контрагенту → типовые слова назначения (эквайринг, комиссия банка, аренда, зарплата, налоги, коммунальные, инкассация) → иначе «Не разнесено» (сигнал, без угадывания).
При ручном разнесении «запомнить» создаёт правило и разносит такие же неразнесённые движения.

## Отчёт «Деньги» (`v75GetCash`)

Счета (на начало, поступило, выплачено, на конец); Cash Flow по статьям и видам деятельности (операционная, инвестиционная, финансовая); переводы между своими счетами (инкассация) в поступления и выплаты не входят; выручка по продажам против поступлений выручки; долги поставщикам (накладные приёмки − оплаты, оплата гасит самые старые накладные, давность); история загрузок; предупреждения.

## Связь с остальным

Движения — этап «Деньги» в журнале V64 → реестр операций (CASH) → дневные итоги (`cashIn`, `cashOut`, `cashUncat`, колонки справа). P&L деньги не меняют.
Сводка руководителя: «Деньги на конец периода», «Долг поставщикам», сигналы (отрицательный остаток, не разнесено, накладные старше 30 дней).

## Экран

«Экономика» → вкладка «Деньги»: итоги, счета, загрузка выписки, Cash Flow, разнесение, касса и банк вручную (в т. ч. перевод между счетами), новый счёт, долги поставщикам, движения, история загрузок.
