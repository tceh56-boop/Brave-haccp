# ЦЕХ Финансы и Экономика — этап 1: исправления экономического ядра

Аудит (этап 0) и план согласованы 14.11.2026. Этап 1 исправляет ошибки, найденные аудитом. Новых экранов нет: правки видны в существующей экономике (V64), отчётах V68 и статистике продаж.

## Что исправлено

| Было | Стало |
|---|---|
| Акты списания (питание персонала, порча, проработка, представительские, недостача) не попадали в экономику | Строки этапа «Отходы и брак» по каждой списанной партии, по цене партии. Причина списания — в строке и в разрезе `wasteByReason` |
| Списание вручную и по истёкшему сроку не попадали в экономику | Попадают. Новые записи связаны с партиями (`СПИСАНА_ВРУЧНУЮ`, `СПИСАНА_ПО_СРОКУ`). Старые без партий оцениваются по журналу склада с признаком «по средней цене» |
| Недостача и излишек по ревизии не попадали в экономику; найденный излишек выглядел как закупка без цены | Этап «Инвентаризация» (недостача — расход, излишек — приход), по цене партии. Найденный излишек оценивается по средней цене с признаком. В «вкладе после потерь» учитываются оба |
| Расход оценивался по двум разным ценам (партия и средняя цена остатка) | Одно правило `_mcCostOfConsumed_`: цена списанных партий; средняя цена только для части без партии или без цены, с признаком. Акт списания и ручное списание считают сумму так же |
| Продажа в экономике называлась «J36-номер строки»: удаление или сортировка строк путали снимки и корректировки | Постоянный ID: номер продажи `SL-…`, иначе хеш содержимого и момента внесения. Старые снимки по номеру строки один раз переносятся на новый ID с прежней суммой |
| Утверждённое исправление журнала продаж не меняло выручку в экономике | Действует: экономика и статистика берут исправленные значения, строка с признаком «по утверждённому исправлению журнала» |
| Два расчёта выручки (`getSalesStats` и экономика) | Один источник строк и одно правило суммы (`_mcSaleRows_`, `_mcSaleAmount_`) |
| Закрыть можно было и сегодняшний день, тогда текущие операции попадали в закрытый период | Закрывается только период до сегодняшнего дня. Исправление журнала продаж в закрытом периоде запрещено (создание и утверждение) |
| Повторное нажатие или обрыв связи могли записать продажу дважды | Номер запроса: повтор возвращает уже записанную продажу. Такая же продажа за последние 2 минуты даёт предупреждение, повторное нажатие записывает вторую |
