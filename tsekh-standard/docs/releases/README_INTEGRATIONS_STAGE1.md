# Интеграция с учётными системами — этап 1: продажи из отчёта кассы

План: 1 — общая основа и загрузка продаж из файла (этот этап) → 2 — iiko по API → 3 — 1С → 4 — R-Keeper по XML-интерфейсу.

Новый модуль: `app/MonChef_V77_Integrations.gs`. Экран: «Экономика» → вкладка «Кассы и 1С».

## Как продажа из кассы попадает в ЦЕХ

Продажа из кассы проводится **тем же путём, что ручная продажа**: строка журнала продаж J36 с номером SL-…, списание склада по партиям (V71: готовые партии, затем п/ф и сырьё по ТТК), связь партий с продажей, факт, экономика, реестр операций, P&L. Для этого запись продажи вынесена из `mcSaleAdd` в общую функцию `_mcSaleWrite_` (`MonChef_LegacyBack.gs`); поведение ручной продажи не изменилось.

В источнике записи журнала: `загрузка iiko · чек 101 · SL-… · ext:<ключ>`.

## Листы

| Лист | Что хранит |
|---|---|
| `Инт_Сопоставление` | позиция кассы (код или название) → блюдо по ТТК, товар со склада или «не учитывать»; коэффициент (единиц ЦЕХ в одной продаже кассы). Прежнее сопоставление при изменении уходит в архив |
| `Инт_Продажи` | каждая строка продажи из кассы. Ключ `ExtKey` (система + дата, время, чек, позиция, количество, сумма + номер повтора в файле): повторная загрузка того же или пересекающегося отчёта ничего не задваивает. Статус: проведена (SaleID), ждёт сопоставления, не учитывается, закрытый период, ошибка |
| `Инт_Загрузки` | каждая загрузка: система, файл или API, период, проведено, повторов, ждут, не учтено, закрытый период |

## Правила

- Позиция, название которой **точно** совпадает с блюдом ТТК или товаром на складе, сопоставляется сама (в сопоставлениях видно «точное совпадение названия»). Остальное не угадывается: строки ждут, пока пользователь укажет, что это. После сопоставления все ждущие строки позиции проводятся сразу.
- «Не учитывать» — для обслуживания, доставки, модификаторов: в продажи блюд они не идут.
- Возвраты (количество ≤ 0) не проводятся — оформляются вручную.
- Закрытый финансовый период и подписанный журнал продаж — строка не проводится (статус «закрытый период»).
- Нет времени в отчёте — продажа записывается на 12:00 дня.

## Файл

- Excel `.xlsx` читается прямо в браузере (без библиотек), CSV — с разделителем `;`, `,` или табуляцией, в UTF-8 или Windows-1251. Старый `.xls` — пересохранить.
- Строка заголовка ищется в первых 40 строках. Колонки по названию: дата («Учетный день», «Дата»…), время, чек, код, позиция («Блюдо», «Наименование»…), количество, цена, сумма («Сумма со скидкой» важнее «Сумма без скидки»), официант. Строки «Итого/Всего» пропускаются. Даты Excel числом понимаются.
- Нет колонки с датой — дата указывается на экране.
- «Проверить файл» показывает период, сумму и позиции без сопоставления, ничего не записывая.
