# ЦЕХ Финансы и Экономика — этап 3: P&L и CEO Dashboard

Основа — этап 2 (реестр операций и дневные итоги). Новый модуль: `app/MonChef_V73_PnL.gs`.
Источник цифр — только дневные итоги (`Фин_Итоги_День`, `Фин_Итоги_Блюдо_День`): своих данных модуль не вводит и журнал не пересобирает.

## Управленческий P&L (`v73GetPnL(token, from, to)`)

| Строка | Откуда |
|---|---|
| Выручка | продажи (с исправлениями журнала, скидками и возвратами денег) |
| − Себестоимость продуктов, − Упаковка | партии FEFO, нормы упаковки |
| **= Валовая прибыль** | |
| − Списания и брак, − Дефрост, − Возвраты, − Инвентаризация (недостача − излишек) | акты, события партий, ревизии |
| **= Вклад после потерь** | |
| − ФОТ (Labor Cost) | расход «Фонд оплаты труда» (табель и ставка × часы — этап 4) |
| − Прочие расходы по статьям | `Финансы_Расходы`, фин. операции без распределения (доставка, лаборатория) |
| − Корректировки закрытых периодов | подтверждённые корректировки |
| **= EBITDA**, − Амортизация, **= Операционная прибыль** | |

У каждой строки: сумма, % выручки, прошлый период той же длины, изменение в ₽ и %.
Коэффициенты: food cost, упаковка, labor cost, prime cost, потери, валовая маржа, EBITDA, операционная маржа.

## CEO Dashboard (`v73GetCeoDashboard(token, from, to)`)

- 11 показателей с динамикой к прошлому периоду и оценкой «хорошо / плохо» по ориентиру.
- По дням, топ блюд, блюда с маржой ниже ориентира, потери по причинам.
- Сигналы: food / labor / prime cost и потери выше ориентира, слабые блюда, дни с отрицательной валовой прибылью, падение выручки > 10 %, продажи без цены, записи без цены закупки, нет ФОТ, итоги давно не сверялись, изменения в закрытых периодах.

## Ориентиры (`v73GetTargets`, `v73SetTargets` — право `finance_edit`)

По умолчанию: food cost ≤ 32 %, labor cost ≤ 30 %, prime cost ≤ 62 %, потери ≤ 3 %, маржа блюда ≥ 60 %. Это типовые значения — их стоит заменить своими. Изменение пишется в аудит.

## Без подмены данных

- ФОТ не внесён → строка 0 и сигнал «ФОТ не внесён»; labor и prime cost не оцениваются по ориентиру.
- Дни, посчитанные на этапе 2 (без разбивки расходов по статьям) → сумма идёт строкой «Без разбивки по статьям» и подсказка сделать полный пересчёт.
- Итоги не сверялись больше 30 минут → отчёт сначала сверяет их сам.

## Экран «Экономика»

Сверху — показатели руководителя с прошлым периодом и ориентиром, плюс показатели качества данных. Новые вкладки: «P&L», «Сигналы», «По дням». Прежние вкладки V64 (блюда, банкеты, цеха, проблемные записи, закрытые периоды) остались.
