# Mon Chef V70 — база нормативов и сроков годности на Google Диске

Папка на Диске с нормативными документами (свойство MC_NORMS_FOLDER_ID) — источник реестра нормативов, норм и сроков годности.

## Файлы
| Файл | Что делает |
|---|---|
| `MonChef_V70_NormData.gs` | каталог 19 документов (номер, название, класс, шаблон имени файла, SHA-256) и 31 норма, выписанная из PDF папки дословно: документ, пункт, страница, цитата, SHA-256 файла |
| `MonChef_V70_NormBase.gs` | синхронизация папки, реестр со ссылками, проверка норм ответственным за ХАССП, таблица сроков предприятия, подстановки во входной контроль, приёмку, этикетки, срок после вскрытия, ППК |

## Правила
- Норма применяется только со статусом «утверждена». Файл изменился → «проверить», файла нет → «нет файла»; применение снимается.
- Строка таблицы сроков без источника или срока не загружается; изменённая строка снова уходит на проверку.
- Сроков годности, которых нет в документах или таблице, система не подставляет.
- Технический доступ задаёт папку и синхронизирует, но нормы не утверждает.

## Экран
`?normbase=1` — «Нормативы: база на Google Диске» (HACCP, Настройки).
