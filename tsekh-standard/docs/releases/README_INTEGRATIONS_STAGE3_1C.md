# Интеграция с учётными системами — этап 3: 1С

Новый модуль: `app/MonChef_V77_1C.gs`. Экран: «Экономика» → «Кассы и 1С» → карточки «1С: выгрузка для бухгалтерии» и «1С: поступления товаров по сети».

Два направления, и ни одно не перезаписывает данные: ЦЕХ не меняет базу 1С, 1С не меняет приёмку и склад ЦЕХ.

## ЦЕХ → 1С: файл (`v77Export1C`)

Работает с любой конфигурацией 1С («Бухгалтерия», «Общепит», «Розница», УТ) без программиста: таблица CSV (разделитель «;», десятичная запятая, UTF-8 с BOM — Excel и 1С читают кириллицу). Имя файла латиницей: `tsekh_1c_<sales|writeoffs|purchases>_<с>_<по>.csv`.

| Что | Откуда в ЦЕХ | Колонки | Документ в 1С |
|---|---|---|---|
| Продажи | журнал продаж J36 (ручные и из кассы), по дню и блюду | Дата, Номенклатура, Код (из ТТК), Количество, Ед., Цена, Сумма | «Отчёт о розничных продажах» |
| Списания | журнал экономики V64, этап WASTE: акты списания, списания вручную и по сроку | Дата, Номенклатура, Количество, Ед., Сумма (себестоимость партий), Причина, Документ ЦЕХ | «Списание товаров» |
| Поступления | `Приёмка_Партии` + `Склад_Партии`, ИНН из справочника поставщиков | Дата, Поставщик, ИНН, Накладная, Номенклатура, Количество, Ед., Цена, Сумма, Партия ЦЕХ | сверка с «Поступлением товаров» |

В 1С: документ → табличная часть → «Загрузить из файла» (или обработка «Загрузка данных из табличного документа»). ЦЕХ ничего не помечает «выгруженным»: повторная выгрузка периода даёт тот же файл, задвоение в 1С проверяет бухгалтер.

## 1С → ЦЕХ: поступления по OData (`v77OneCSave`, `v77OneCPull`, `v77OneCDisconnect`)

- Нужно: база 1С опубликована на веб-сервере, включён «Стандартный интерфейс OData», в его состав добавлены `Document_ПоступлениеТоваровУслуг`, `Catalog_Контрагенты`, `Catalog_Номенклатура`, `Catalog_КлассификаторЕдиницИзмерения`. Это настраивает программист 1С / франчайзи.
- Адрес — адрес публикации (`https://server/buh`); хвост `/odata/standard.odata` можно вводить, он отрезается.
- Вход — Basic (пользователь 1С и пароль). Пароль нужен 1С как есть: хранится в свойствах проекта на сервере ЦЕХ, в экран и аудит не попадает; пустое поле при повторном сохранении — прежний пароль.
- Загрузка: проведённые и не помеченные на удаление поступления за период (до 92 дней) → лист `Инт_Накладные_1С` (те же колонки, что `Инт_Накладные_iiko`), ключ `1c:<Ref_Key>:<LineNumber>`, повтор не задваивает. Контрагенты, номенклатура и единицы подгружаются по ссылкам пачками по 40.
- Сверка с `Приёмка_Партии` — то же правило, что для накладных iiko: по номеру входящего (или внутреннего) документа и поставщику. **Поступление в 1С без приёмки в ЦЕХ** — товар не прошёл входной контроль. Партии автоматически не создаются.
- Если в конфигурации клиента объекты называются иначе, названия меняются в настройках (`names`, по умолчанию `MC_V77_1C_NAMES`).

## Права

`v77Export1C` — `finance_view`; `v77OneCSave`, `v77OneCDisconnect` — `finance_edit`; `v77OneCPull` — `finance_edit | receiving | procurement`.
