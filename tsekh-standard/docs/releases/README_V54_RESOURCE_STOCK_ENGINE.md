# Mon Chef V54 — Resource / Stock Engine

V54 — архитектурная консолидация склада и ресурсов.

## Цель
Не создавать новый склад, а ввести единый транзакционный слой поверх существующего `Склад_Партии`.

## Что добавлено
- единая привязка BatchID → ProductID;
- статус сопоставления APPROVED / REVIEW;
- каноническая единица и количество без изменения физического остатка;
- единый фасад для consume / adjust / reserve / release;
- блокировка `_withLock_` для изменяющих операций;
- OperationID + отдельный V54 operation log + audit;
- защита от резерва поверх уже зарезервированного остатка;
- idempotent release reservation;
- readiness check.

## Важное правило
Партия без APPROVED ProductID не блокируется физически, но не должна использоваться автоматикой, пока сопоставление не подтверждено.

## Route
`?resourcestock=1&token=...`

## Миграция
`v54MigrateBatchResourceIds(token)` только добавляет служебные колонки в `Склад_Партии` и рассчитывает идентичность. Количество партии не изменяется.
