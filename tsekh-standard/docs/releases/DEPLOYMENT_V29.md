# Deployment V29

1. Откройте копию проекта Apps Script, связанного с рабочей книгой Mon Chef.
2. Добавьте `MonChef_V29_BanquetClosure.gs` как новый server-side файл.
3. Добавьте `Closure.html` как HTML-файл.
4. Замените `Code.gs` версией из пакета.
5. Сохраните проект и выполните Deploy → New deployment / Manage deployments.
6. В тестовой копии выполните сквозной сценарий:
   - создать банкет;
   - проверить V26 dispatch;
   - подтвердить pick V23;
   - выпустить партию V27;
   - выдать готовое блюдо V28;
   - открыть `?closure=1&token=...`;
   - распределить выданное количество между обслужено/возврат/брак;
   - закрыть банкет;
   - проверить листы V29, J36, J02 и Audit_Log;
   - повторить закрытие и убедиться, что система отклоняет повторную операцию.
7. После успешного теста опубликовать новую версию web app.

Не удаляйте старые листы/модули V14–V28: V29 использует существующие ядра авторизации, блокировок, склада, FEFO, FACT, Audit и банкетов.
