# Mon Chef V20 — Weekly Production Dispatcher

V20 делает недельный производственный расчёт рабочим диспетчерским слоем поверх V14.

## Поток

Банкеты недели → расчёт ТТК → потребность → текущий остаток → дефицит → закупка → П/Ф → производственные задачи → публикация плана.

## Новые серверные API

- `getWeeklyDispatcher(date, token)` — сводка недели.
- `createWeeklyDispatcherPlan(date, token)` — пересчитать и сохранить план.
- `publishWeeklyDispatcherPlan(planId, token)` — опубликовать план.
- `getWeeklyPurchasePlan(planId, token)` — получить закупочную часть.
- `runMonChefWeeklyDispatcherCycle(token)` — фоновый расчёт следующей недели.
- `installMonChefWeeklyDispatcherTrigger(token)` — ежедневный триггер.

## UI

`Weekly.html`, открывается через `?weekly=1&token=...`.

Показывает календарь недели, банкетную нагрузку, производственные задачи, дефициты и закупку. Технические J-коды сотруднику не показываются.

## Важно

V20 не создаёт фиктивные остатки и не подтверждает закупку автоматически. Публикация означает утверждение рассчитанного рабочего плана; фактическое поступление и расход остаются операционными событиями.
