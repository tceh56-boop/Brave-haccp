# Мастер-промт 4.0 — Этап 5. Чек-листы из ППК

Собственность Слепцова Дениса Владимировича. Разработчик кода — Слепцов Денис Владимирович.

Проверено: автотесты на настоящем коде (V65, экран «Сейчас» TS2, связь ТТК → ХАССП, новый модуль) с имитацией таблиц Google. Полный цикл: создать ППК → сформировать → ввести → задачи дня → «Да / Нет» → график ППК. Экраны — в браузере (Playwright, ответы сервера подставлены). **В реальном Apps Script не проверялось.**

## 1. Принцип
- **План** — график действующей ППК V65 (`ППК_График`).
- **Исполнение** — единый контур задач `JOURNAL_EXPECTATIONS` (экран «Сейчас»).
- **Форма исполнения** — шаблон чек-листа (`CHECKLIST_TEMPLATES`, новый модуль `app/TS_ChecklistGen.gs`).

Новых параллельных чек-листов, задач и журналов не создаётся. Отметка «выполнено» ставится один раз — на экране «Сейчас» — и сама попадает в график ППК.

## 2. Способ исполнения каждого мероприятия ППК
| Способ | Какие мероприятия | Что делает система |
|---|---|---|
| `TASK` | Периодические без своего контура: верификация ППК, лабораторные исследования, вода, дезинсекция/дератизация, мероприятия, добавленные вручную | Задача на экране «Сейчас» в день срока по графику ППК, с пунктами чек-листа. «Да» — пункт графика `DONE`. «Нет» — `DEVIATION` и отклонение ответственному. Пропущено двое суток — `MISSED`. В графике ссылка на факт (автозапись) |
| `COVERED` | Температура хранения, допуск смены, санитарная обработка зон и санитарные планы, концентрация растворов | Не дублируется: в шаблоне указано, каким разделом уже исполняется |
| `EVENT` | Входной контроль, бракераж, ККТ «каждая партия», меры по операциям ТТК «при каждой выработке» | Исполняется записью события, не ежедневной задачей |
| `DATE` | Медосмотры, поверка средств измерений | Контроль сроков (правила R-006, R-009, реестры) |
| `NO_SCHEDULE` | Мероприятие без периодичности | Пробел. Периодичность не придумывается, задача не создаётся |

**Пункты чек-листа** берутся из мероприятия ППК, ничего не дописывается:
- «Выполнено: …»;
- способ;
- норматив, если он задан в ППК;
- доказательство: протокол лаборатории, документ или акт, отметки чек-листа, запись в журнале.

Действие при несоответствии показывается на экране.

## 5. Ограничения
- Способ исполнения определяется по тексту мероприятия (периодичность, параметр). Мероприятие, добавленное вручную с нестандартной формулировкой периодичности, может уйти в «по событию». Шаблон это показывает, периодичность исправляется в ППК.
- «Нет» закрывает задачу целиком: пункты чек-листа отдельно не отмечаются. Невыполненный пункт записывается в причину.
- Мероприятия «по событию» (меры по операциям ТТК при выработке) пока исполняются существующими событиями (выпуск, бракераж). Отдельная форма по событию выработки — этап 6.
