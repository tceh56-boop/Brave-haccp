# Мастер-промт 4.0 — Этап 8. Интерфейс цепочки контроля

Собственность Слепцова Дениса Владимировича. Разработчик кода — Слепцов Денис Владимирович.

Проверено: экраны в браузере (Playwright, Chromium) на ширине телефона 390 px и на обычном экране, ответы сервера подставлены; серверная часть (запись-доказательство) — автотестом на настоящем коде с имитацией таблиц. **В реальном Apps Script и на настоящем телефоне не проверялось.**

## 1. Что сделано
| Что | Как |
|---|---|
| **Полоса «цепочка контроля»** | Процессы ТТК → Опасности ХАССП → ППК → Чек-листы → Сейчас → Нарушения → Аудит 360°. Вверху экранов «Процессы ТТК», «Чек-листы ППК», «Нарушения», «Аудит 360°». Текущий шаг выделен (`aria-current`), недоступные по роли — приглушены (сервер всё равно проверяет права). «Опасности ХАССП» открывает нужную вкладку «Процессов ТТК». На экране повара «Сейчас» полосы нет, чтобы не мешать смене |
| **Переход к записи-доказательству** | В аудите 360° ID доказательств — ссылки. Карточка записи показывает, что это, лист и все поля; у нарушения — все действия и проверки. Кнопка «Открыть раздел» ведёт туда, где запись исправляется. Сервер: `a360Evidence` — замечания ТТК, операции, связи с опасностями, чек-листы, задачи смены, факты, опасности, процессы и ККТ V30, пункты графика и версии ППК, нарушения, прогоны контрольного листа. Неизвестный ID — «запись не найдена» |
| **Экран «Нарушения»** | Единый реестр (этап 6) отдельным экраном: счётчики (открыто, повторно, ждут проверки, критических), фильтр по статусу, источник (журналы, экран «Сейчас», санитария, дезсредства, задачи), кто устранил, ссылка на запись. Кнопки «Устранено» (действие и доказательство), «Подтвердить», «Не устранено». Для директора — режим «кто подтверждает устранение» с подтверждением выбора |
| **Телефон** | Все экраны цепочки на 390 px — без горизонтальной прокрутки. Таблицы на узком экране — карточки (существующий механизм `vTable`). Карточка записи с длинными значениями переносит текст и не выходит за край |

## 2. Тесты
- `tests/chain_mobile.browser.test.js` (новый, телефон 390 px):
  - 8 экранов (процессы ТТК, чек-листы, «Сейчас», нарушения, аудит 360°, оба прежних раздела ППК, ППК) — без горизонтальной прокрутки;
  - полоса цепочки: отметка текущего шага и переход в «Опасности ХАССП»;
  - из аудита — ссылка на опасность → карточка записи (тоже без прокрутки) → «Открыть раздел»;
  - нарушения: «Устранено», «Подтвердить», смена режима;
  - ошибок страницы нет.
- `tests/audit360.test.js` — сценарий записи-доказательства: замечание ТТК, опасность V30, нарушение с действиями, неизвестный ID.
- Все 24 набора проходят; сборка проходит; инвентаризация точек входа — нарушений нет.

Не проверено: настоящий телефон (iOS Safari, Android Chrome), экранные дикторы, скорость `a360Evidence` на больших листах (полное чтение листа для части видов записей).

## 3. Ограничения
- Карточка записи показывает поля как в таблице (названия колонок листа); у листов TS2 — английские имена полей. Перевод подписей — этап 9 (вместе с проверкой интерфейса).
- Переход «Открыть раздел» ведёт к разделу, а не к строке в нём: экраны разделов пока не умеют подсвечивать конкретную запись.
