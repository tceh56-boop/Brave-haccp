# ЦЕХ Стандарт — развёртывание, распознавание, почта

Пошаговая инструкция для владельца. Все действия выполняются в браузере Chrome на компьютере под тем
Google-аккаунтом, которому принадлежит рабочая таблица и папка установки.

---

## Часть 1. Развёртывание системы кухни

### 1.1. Подготовка (5 минут)

1. **Резервная копия таблицы.** Откройте рабочую таблицу → «Файл → Создать копию», назовите
   «Резервная копия до ЦЕХ Стандарт».
2. **Apps Script API.** Откройте https://script.google.com/home/usersettings и включите «Google Apps Script API».
3. **Папка установки на Диске** — та же, что для MonChef. Перенесите старые архивы `MonChef_*.zip` и файл
   `MonChefPatches.json` в подпапку «Старые сборки».
4. Загрузите в эту папку файл **`2_Загрузить_на_Диск/TsekhStandard_Application.zip`**. Распаковывать его не нужно.

### 1.2. Установщик (5 минут)

1. Откройте проект-установщик на https://script.google.com: это проект, в котором есть функция `installMonChef`.
   Если его нет, создайте новый проект.
2. Замените весь текст `Код.gs` содержимым файла **`3_Установщик/TsekhInstaller.gs`**.
3. «Настройки проекта» (шестерёнка) → включите «Показывать файл манифеста appsscript.json». Замените его
   содержимое файлом **`3_Установщик/appsscript.json`**.
4. Проверьте три строки вверху `Код.gs`:
   * `MC_INSTALL_FOLDER_ID_` — ID папки установки (часть адреса папки после `folders/`). Ваш ID уже вписан.
   * `MC_USE_SHEET_COPY_ = true` — пилот на копии таблицы. Для рабочей таблицы поставьте `false` (см. 1.6).
   * `MC_TARGET_SCRIPT_ID_ = ''` — оставьте пустым.
5. Нажмите «Сохранить».

### 1.3. Установка (3 минуты)

1. Выберите функцию **`installTsekhStandard`** → «Выполнить» → «Проверить разрешения» → ваш аккаунт.
   Если появится «Google не проверил это приложение», нажмите «Дополнительные настройки → Перейти»: это ваш собственный скрипт.
2. В «Журнале выполнения» появятся ссылки **«Проект»** и **«Веб-приложение»**. Сохраните ссылку на веб-приложение —
   это адрес системы для сотрудников. При обновлениях он не меняется.

> Если система MonChef уже была установлена, установщик обновит тот же проект и то же развёртывание.
> Ссылка для сотрудников останется прежней, данные в таблице сохранятся.

### 1.4. Проект «ЦЕХ Стандарт» (2 минуты)

Откройте ссылку «Проект» из журнала и выполните по очереди:

1. **`installAllTriggers`** — автозапуски журналов и задач. Google попросит новые разрешения (почта, отправка писем) — разрешите.
2. **`installTsTriggers`** — ежедневная проверка лицензии.

### 1.5. Первый вход

1. Откройте ссылку на веб-приложение. Войдите с кодом технического доступа (по умолчанию **2258**).
2. «Настройки» → «Миграция данных», затем «Перенос ролей», «Защита журналов». После этого смените код 2258 на свой.
3. Назначьте директора и выдайте ПИН-коды сотрудникам (ДОК_10, шаг 9).
4. Меню → **«Подписка»**: директор вводит ключ лицензии, секрет и адрес админ-панели (см. часть 2).
   Без ключа работает пробный период: 14 дней, все возможности.

### 1.6. Переход с копии на рабочую таблицу

Когда пилот прошёл успешно, в установщике поставьте `MC_USE_SHEET_COPY_ = false` и снова запустите
`installTsekhStandard`. Система переключится на рабочую таблицу, ссылка не изменится.

## Часть 2. Развёртывание админ-панели (для поставщика, один раз)

1. https://script.google.com → «Новый проект», назовите «ЦЕХ Стандарт Admin».
2. Создайте файлы и вставьте в них содержимое из папки **`5_Админ-панель/`**:
   * скрипты (`+` → «Скрипт»): `Config`, `Database`, `Helpers`, `Logger`, `Security`, `Users`, `Admin`, `Licenses`,
     `Subscriptions`, `Payments`, `Notifications`, `Analytics`, `Reports`, `API`, `Main`;
   * HTML (`+` → «HTML»): `Index`, `Logo`;
   * `appsscript.json` — через «Показывать файл манифеста», как в п. 1.2.
3. Выберите **`setupAdmin`** → «Выполнить» → разрешите доступ. В журнале выполнения появятся ваш email
   и **временный пароль**. Сохраните пароль.
4. Выберите **`installTriggers`** → «Выполнить». Это ежедневные напоминания клиентам и аналитика.
5. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»:
   * «Запуск от имени»: **Я**;
   * «У кого есть доступ»: **Все**. Это нужно, чтобы системы клиентов проверяли лицензию, а ЮKassa и ЮMoney
     присылали уведомления об оплате. Сама панель закрыта паролем.
6. Скопируйте ссылку `https://script.google.com/macros/s/…/exec`. Это и адрес панели, и **адрес админ-панели**
   для экрана «Подписка» у клиентов.
7. Откройте ссылку и войдите. Сразу смените пароль: внизу меню «Сменить пароль».
8. «Клиенты» → «+ Новый клиент» → выберите тариф. Панель покажет **License Key** и **секрет** (секрет показывается
   один раз). Передайте клиенту ключ, секрет и адрес панели.

> Если вы поменяли код админ-панели, нажмите «Развернуть → Управление развёртываниями → ✎ → Версия: новая → Развернуть».
> Ссылка останется прежней.

## Часть 3. Распознавание (накладные, этикетки, бланки банкетов, AI-ассистент)

Распознавание работает через **Yandex Cloud**: Vision OCR читает фото и PDF, YandexGPT разбирает бланки и
работает в ЦЕХ AI. Нужны два значения: **API-ключ** и **ID каталога**.

### 3.1. Создать ключ в Yandex Cloud (10 минут)

1. Зайдите на https://console.yandex.cloud и создайте платёжный аккаунт (распознавание платное, по запросам).
2. Откройте каталог (folder) и скопируйте его **ID** — строку вида `b1g…`. Это **YANDEX_FOLDER_ID**.
3. «Сервисные аккаунты» → «Создать сервисный аккаунт», например `tsekh-ocr`. Выдайте ему роли на этот каталог:
   * **`ai.vision.user`** — распознавание фото и PDF;
   * **`ai.languageModels.user`** — YandexGPT (бланки банкетов и ЦЕХ AI).
4. Откройте сервисный аккаунт → «Создать новый ключ» → **«Создать API-ключ»**. Скопируйте секрет —
   строку вида `AQVN…`. Это **YANDEX_API_KEY**. Яндекс показывает его один раз.

### 3.2. Вписать ключ в систему

Проект «ЦЕХ Стандарт» → «Настройки проекта» (шестерёнка) → «Свойства скрипта» → «Добавить свойство»:

| Свойство | Значение |
|---|---|
| `YANDEX_API_KEY` | `AQVN…` (секрет API-ключа) |
| `YANDEX_FOLDER_ID` | `b1g…` (ID каталога) |
| `BANQUET_GPT_MODEL` | необязательно; по умолчанию `yandexgpt/latest` |
| `TS_AI_MODEL` | необязательно, модель для ЦЕХ AI; по умолчанию `yandexgpt/latest` |

Нажмите «Сохранить свойства скрипта».

> Не храните ключ в Google Docs и не пересылайте его в чатах. Если ключ уже лежал в открытом документе,
> удалите его в Yandex Cloud и создайте новый.

### 3.3. Проверить

В системе: «Банкеты» → «+ Новый банкет» → **«🔑 Проверить Yandex»**. Система сделает два коротких запроса
и сообщит результат:
* «Ключ не принят (401)» — ключ неверный или удалён, создайте новый (п. 3.1.4);
* «Нет доступа (403)» — сервисному аккаунту не выданы роли из п. 3.1.3;
* «Запрос отклонён (400)» — неверный `YANDEX_FOLDER_ID`.

После этого работают: скан накладных при приёмке, фото этикеток, скан пачкой бланков банкетов
и ЦЕХ AI (тариф Pro Max). Без ключей система работает, но данные с фото нужно вводить вручную.

## Часть 4. Почта

Письма отправляются **через Gmail аккаунта, от имени которого развёрнута система** (сервис MailApp).
Отдельный почтовый сервер настраивать не нужно.

### 4.1. Почта системы кухни

1. При запуске `installAllTriggers` (п. 1.4) Google запросит разрешение «Отправлять письма от вашего имени».
   Его нужно дать. Без него письма не уходят, а служебные функции пишут «Сессия не найдена».
2. Куда слать тревоги. Проект «ЦЕХ Стандарт» → «Свойства скрипта» → добавьте:

   | Свойство | Пример | Что приходит |
   |---|---|---|
   | `MC_NOTIFY_EMAIL` | `haccp@ваш-ресторан.ru` | непогашенные ВСД, критические отклонения ХАССП, подбор ПИН-кода. Несколько адресов — через запятую |

   Без этого свойства письма уходят владельцу таблицы.
3. Кому и какие уведомления ХАССП отправлять (получатель, повтор, эскалация) — в приложении на экране «ХАССП — сегодня», блок настроек уведомлений.

### 4.2. Почта админ-панели

1. При первом запуске `setupAdmin` разрешите отправку писем.
2. Письма клиентам (напоминания об окончании подписки, рассылки, сообщения из карточки клиента)
   уходят с аккаунта, от имени которого развёрнута панель. Отправитель отображается как «ЦЕХ Стандарт».
3. Остаток писем на сегодня виден в «Настройки → Почта».

### 4.3. Лимиты Google

| Аккаунт | Писем в сутки |
|---|---|
| Обычный Gmail (@gmail.com) | около 100 получателей |
| Google Workspace (свой домен) | около 1500 получателей |

Для рассылки большому числу клиентов разверните админ-панель от аккаунта Google Workspace на своём домене.
Тогда письма будут приходить с адреса вашего домена и реже попадать в спам.

## Часть 5. Оплата ЮMoney / ЮKassa (админ-панель)

1. Админ-панель → «Настройки» → «Платёжная система»:
   * **ЮKassa** — в «Script Properties» впишите `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET` (секретный ключ из кабинета ЮKassa);
   * **ЮMoney (кошелёк)** — `YOOMONEY_WALLET` (номер кошелька) и `YOOMONEY_NOTIFY_SECRET` (секрет
     HTTP-уведомлений из настроек кошелька).
2. Скопируйте **адрес webhook** из «Настройки» и вставьте его в кабинет ЮKassa (HTTP-уведомления, событие
   `payment.succeeded`) или в настройки HTTP-уведомлений ЮMoney.
3. Выставьте клиенту счёт: «Платежи → + Счёт» или «Подписки → Продлить». После оплаты подписка продлится
   автоматически, клиент получит новый срок при следующей проверке лицензии.

## Если что-то не работает

| Сообщение | Что сделать |
|---|---|
| «нет файла Code.gs / Console.html» при установке | В папке лежит не тот архив: нужен `TsekhStandard_Application.zip` без распаковки |
| «Сессия не найдена» в редакторе | Запустите `installAllTriggers` и дайте все разрешения |
| «Ключ не подтверждён админ-панелью» на экране «Подписка» | Проверьте ключ, секрет и адрес панели (он заканчивается на `/exec`); панель развёрнута с доступом «Все» |
| Плашка «Только просмотр» | Подписка истекла или клиент заблокирован — продлите подписку в админ-панели |
| Письма не приходят | Нет разрешения на отправку почты, исчерпан дневной лимит или письма попали в спам |
