# ЦЕХ — Stage 33: Operational Closing & Month-End Engine

Stage 33 добавляет контроль готовности периода к закрытию.

## Принцип
Проверка read-only: она не проводит деньги, не списывает склад, не закрывает производство и не меняет HACCP/Recall.

Жизненный цикл:
`CHECK → READY/BLOCKED → APPROVED → CLOSED`

Автоматический ежедневный триггер только формирует контроль предыдущего календарного месяца. Он не утверждает и не закрывает период.

## Контроли
- незакрытые reconciliation cases;
- критические/высокие расхождения traceability;
- незавершённое производство;
- незакрытая инвентаризация;
- открытые заявки на закупку (warning);
- продажи с незавершённым исполнением;
- открытые критические инциденты;
- открытый карантин;
- открытый Recall;
- HACCP BLOCK;
- непроведённые cash transactions (warning).

## API
`RUN_PERIOD_CLOSING_CHECK`, `GET_PERIOD_CLOSURE`, `GET_PERIOD_CLOSURE_SUMMARY`, `APPROVE_PERIOD_CLOSURE`, `CLOSE_PERIOD`.

Закрытие периода требует явного approve и отдельного close. Универсальная блокировка всех бизнес-операций по закрытому периоду намеренно не включена в этот этап: её следует вводить после аудита всех mutation-paths, чтобы не оставить обходной путь.
