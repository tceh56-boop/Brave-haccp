# Новая система: MON CHEF как основа + функции ЦЕХ

Решение владельца: за основу берётся MON CHEF. Его механика (склад, партии FEFO, производство, банкеты,
журналы ХАССП, аудит, права) проработана лучше. Из ЦЕХ в MON CHEF переносятся функции, которых в
MON CHEF нет или которые там слабее. Код ЦЕХ (`gas/`) остаётся в репозитории как источник для переноса.

* `monchef/app` — код MON CHEF «Integrated Application 1.0»: 104 файла `.gs`, 2299 функций,
  синтаксис проверен, повторов функций нет.
* `monchef/docs` — документы MON CHEF и опись `ОПИСЬ_MON_CHEF.md`.
* `docs/ОПИСЬ_ЦЕХ.md` — опись ЦЕХ.
* `monchef/data/kbju_base_v55.csv` — база КБЖУ MON CHEF V55 (1549 строк, все в статусе REVIEW,
  без документа-источника).

## Что берём из MON CHEF как есть

| Контур | Механика MON CHEF |
|---|---|
| Склад и приход | Приёмка в карантин → входной контроль по замерам → допуск; корректировка накладной с утверждением; заказы поставщикам; ревизия |
| Партии | FEFO — единственный путь расхода; жизненный цикл партии с цепочкой хешей; срок после вскрытия; граф прослеживаемости |
| Производство | Выпуск п/ф одной операцией (раскладка → списание → партия → журналы); блокировка выпуска без ККТ; канбан; планы |
| Разбор сырья | Баланс веса ±1,5 %, перенос себестоимости, дефрост как ККТ |
| Банкеты | Резерв → канбан → выдача только после бракеража, пробы и ККТ → закрытие; OCR бланка по координатам |
| ХАССП и журналы | J01–J53, ожидаемые проверки, отклонение → КД → блокировка → уведомление с эскалацией; подпись с QR |
| Маркировка, аллергены, КБЖУ, лаборатория, пробы, оборудование | Как в MON CHEF |
| Документы, «Меркурий», портал проверяющего | Как в MON CHEF |
| Аудит, резервные копии, права | Цепочки SHA-256; шлюз прав на все функции (роль, цех, меддопуск, OperationID) |

## Что добавляем из ЦЕХ (нет в MON CHEF или слабее)

| № | Функция ЦЕХ | Что есть в MON CHEF | Как переносим |
|---|---|---|---|
| 1 | Мастер ППК «цифровое предприятие»: помещения и площади, оборудование по категориям, инвентарь с маркировкой, расчёт дезсредств по площади и инструкции | Конструктор ППК V35, дезсредства V41/V43 | Поверх V35/V41: листы помещений, оборудования и инвентаря, расчёт раствора/концентрата на обработку и на месяц |
| 2 | Генератор ХАССП: анализ опасностей → ККТ → пределы с источником, проверка готовности, версии ППК | План ХАССП V30 (без экрана мониторинга) | Достроить V30: анализ опасностей, проверка готовности перед утверждением |
| 3 | ККТ из этапов ТТК → черновик ППК → журналы по каждой партии | Блокировка выпуска без ККТ | Предложения ККТ из технологии ТТК с утверждением технологом |
| 4 | Технические условия по ГОСТ Р 51740 из ТТК: КБЖУ с потерями, рецептура на 100 кг, документ ТУ | КБЖУ для этикеток | Новый модуль ТУ на листах ТТК MON CHEF |
| 5 | Нормативный срок годности блюда (самый строгий из норм групп и сроков п/ф, сверх нормы — протокол по МУК 4.2.1847-04) | Правила сроков V38–V40 без экрана | Справочник норм + расчёт + экран |
| 6 | Сопоставление сырья с базой КБЖУ с подтверждением человеком | Автосинхронизация без подтверждения | Добавить шаг подтверждения |
| 7 | QR кассового чека как доказательство закупки (ФН/ФД, защита от повторного чека) | Нет | Новый модуль в приёмке |
| 8 | Охрана труда: инструкции, тесты, допуск к оборудованию, аварийные инструкции по QR | Журнал инструктажей J16, меддопуск | Новый модуль; допуск к оборудованию — в шлюз прав |
| 9 | Экономика: фудкост и каскад цен, P&L, ABC/XYZ, расходы, бюджет | Себестоимость ТТК и партий, ABC | Новый модуль на данных склада и продаж MON CHEF |
| 10 | Продажи: ручной ввод, CSV, iiko | Журнал продаж банкетов J36 | Новый модуль |
| 11 | Закупки: заявки на закупку с согласованием | Заказы поставщикам, норма запаса | Заявки как шаг перед заказом |
| 12 | Уведомления в Telegram и по email | Уведомления внутри системы с эскалацией | Каналы доставки |
| 13 | Инструкция для персонала по образцу MON CHEF, логотип | ДОК_9 | Собрать заново по новой системе |

Не переносим: стадии ЦЕХ 42–90 (каркас без экранов, из-за ошибки в `Config.gs` недоступен никому),
AI-Директор (шаблоны фраз без языковой модели), офлайн-очередь ЦЕХ (не работает; в MON CHEF есть своя).

## Порядок работ

0. Основа MON CHEF в репозитории; стенд-эмулятор для MON CHEF; проверка запуска.
1. ППК «цифровое предприятие» (п. 1) — продолжение начатого в ЦЕХ этапа 115.
2. ХАССП: анализ опасностей, готовность, ККТ из ТТК (п. 2–3).
3. ТУ, сроки годности, КБЖУ с подтверждением (п. 4–6).
4. Приёмка: QR чека (п. 7).
5. Охрана труда (п. 8).
6. Экономика, продажи, закупки (п. 9–11).
7. Уведомления (п. 12).
8. Инструкция для персонала и проверка всей системы на стенде (п. 13).

Каждый этап: перенос под листы, роли и интерфейс MON CHEF → проверка на стенде → коммит.
