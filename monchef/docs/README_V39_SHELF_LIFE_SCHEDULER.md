# Mon Chef V39 — Shelf Life + Production Window

V39 превращает утверждённые правила V38 из справочника в ограничение производственного планирования.

## Логика
Для события `EventAt`:
- `EarliestProductionAt = EventAt - ShelfLifeHours`, если срок хранения задан;
- `LatestProductionAt = EventAt - RealizationHours`, если срок реализации задан;
- `FreezeLatestProductionAt = EventAt - FreezeShelfLifeHours`, если заморозка разрешена и срок замороженного хранения задан.

Это расчёт бизнес-окна, а не самостоятельное нормативное решение.

## Статусы
- `OK`
- `TOO_EARLY`
- `TOO_LATE`
- `NO_WINDOW`
- `INVALID_RULE`

## Правило безопасности
Нет APPROVED правила → нет автоматического срока и нет автоматического производственного окна.

V39 не переносит старые универсальные сроки из исторических СанПиН в код. Значения должны приходить из утверждённого правила предприятия/применимого нормативного или технического основания.

## Интеграция
Следующий этап: V40 должен передавать сюда реальные узлы V37 Recipe Graph и банкетные события, после чего одно и то же П/Ф будет агрегироваться по нескольким мероприятиям, а производство будет планироваться с учётом срока, FEFO и доступного остатка.
