# Mon Chef V100 — технические меры по 152-ФЗ (24.11.2026)

По предварительной правовой оценке комплекта (24.11). Правовые решения — за оператором; система сроки и основания не придумывает.

1. **Ключ входа не в адресах**: ссылки и переходы получают одноразовый билет (10 мин, один раз); сервер меняет билет на ключ и удаляет его. Повторно открытая ссылка ключа не содержит.
2. **Функции интерфейса — только с ключом входа**, в том числе из браузера владельца таблицы; доверие владельцу (запуск из редактора) — только служебным функциям и расписанию. Проверено: все 1000+ функций сервера без ключа отказывают, кроме 5 открытых без ПД (выход, адрес приложения, перечень журналов, вход, «кто я»). Ключи не встречаются ни в одном листе таблицы.
3. **Медицинские сведения** (номер медкнижки, даты осмотров) — только праву «медкнижки»; кадровым и техническому доступу — без них.
4. **Внешнее распознавание** (Yandex Vision) можно выключить целиком («Персональные данные» → `MC_PD_EXTERNAL_OCR`): документы вносятся вручную. Распознавания медицинских документов в системе нет.
5. **Реестр сроков хранения** (9 категорий: здоровье на смену, медкнижки, кадровые, график, заказчики, аудит, распознавание, резервы, письма) — черновик; срок и основание утверждает ответственный оператора (grants / system), не технический доступ.
6. **Уничтожение** — только по утверждённому сроку: поля ПД в записях старше срока перезаписываются «[уничтожено ДД.ММ.ГГГГ]», даты и обезличенные факты сохраняются; **акт** — дата, основание, категория, способ, число записей и период, затронутые и **не затронутые копии** (резервы, выгрузки, история версий), ответственный, результат. Форму акта оператор сверяет с приказом Роскомнадзора № 179 от 28.10.2022.
7. **Реестр обработки** — кому передаются данные (Google; Yandex Cloud при ключе; адресаты писем) и что оформляет оператор (цели и основания, уведомление РКН, ст. 10, поручения, сроки, политика).

Изменение поведения: функцию интерфейса нельзя вызвать из редактора без входа (нужен ключ входа как аргумент); тест ППК переведён на вызов с ключом.

Листы `ПД_Сроки_V100`, `ПД_Уничтожение_V100`. Файл `MonChef_V100_PersonalData.gs`; изменены `zzz_MonChef_Gate.gs`, `MonChef_Pages.gs`, `Console.html`.
