# Mon Chef V94 — касса (Z-отчёт), паспорта бактерицидных ламп, датчики температуры (24.11.2026)

Экраны: **Касса: Z-отчёты** (Финансы, Главная), **Паспорта ламп и датчики** (Санитария, Оборудование).

## 1. Z-отчёт кассы
- Фото или PDF отчёта о закрытии смены распознаётся (Yandex Vision, как накладные) или вставляется текстом; можно заполнить вручную.
- Разбор по разделам «Приход / Возврат прихода / Расход / Возврат расхода»: наличными, безналичными, итог, число чеков; необнуляемые суммы пропускаются; у каждого поля — исходная строка отчёта. Строки «Кассир / Оператор / ФИО» маскируются.
- Записывает кассир или бухгалтер после проверки полей (галочка): смена, ФН (16 цифр) или ЗН ККТ, приход, возврат; дубль по ФН+ФД или по смене — отказ; дата не позже сегодня.
- **Сверка с журналом продаж** за дату смены: выручка Z (приход − возврат) против суммы журнала (зал и банкеты отдельно), допуск — свойство `MC_V94_Z_TOL` (по умолчанию 0,01 ₽). Расхождение — карточка в «Моей смене», риск FIN_DATA в V93, строка сменного письма.
- Аннулировать записанный отчёт — право «finance_edit», с причиной. MON CHEF не является ККТ и чеки не пробивает.

## 2. Паспорт бактерицидной лампы / облучателя
- Снимок или PDF паспорта → черновик: модель, изготовитель, заводской №, дата выпуска, тип установки, тип и число ламп, мощность, **ресурс лампы (ч) с цитатой строки паспорта**, производительность, режим. Паспорт серии — таблица «Технические характеристики» разбирается по моделям, модель выбирается из списка.
- Подтверждает ответственный за ХАССП; ресурс в «Бактерицидных лампах» берётся из паспорта («Ресурс по паспорту»), прежние значения 8000/9000 ч — «не подтверждён паспортом».

## 3. Датчики температуры — заглушка
- Реестр датчиков по объектам контроля; статус «не подключён — показания вручную». Приём показаний (`v94SensorImport`) отвечает SENSOR_NOT_CONNECTED и ничего не пишет, пока нет образца выгрузки логгеров.
- **Документ датчика** (24.11.2026, по присланной документации Roximo SZTH02): декларация / сертификат соответствия, свидетельство об утверждении типа или поверке — снимок, PDF или текст → черновик: вид, номер, дата регистрации, срок действия, техрегламенты, изготовитель, есть ли модель датчика в перечне. Подтверждает ответственный (галочка), документ виден у датчика.
- Система прямо пишет, что подтверждает документ: **декларация по ТР ТС 020/2011 — электромагнитная совместимость, а не точность измерений**. Для записей в журнал температур нужна проверка по эталонному термометру («Проверка прибора по эталону», J19/J20) или калибровка / поверка («Средства измерения»). Лицо, подписавшее декларацию, телефоны и почта из документа не сохраняются.
- Две присланные декларации (на модель SZTH02 и на серию SZTH) использованы только для проверки разбора на стенде; в архивы и тесты не входят. Подключить показания можно, когда будет образец выгрузки (приложение Roximo IoT / «Умный дом» / шлюз Zigbee).

## 4. Исправление V93
В README V93 и ДОК_7 (2я-15) сказано, что риск инвентаризации — INSUFFICIENT_DATA. С V94 он **считается по ревизиям V49** за 30 дней: строки с расхождением, сумма — по цене партии, владелец — кладовщик; «не рассчитано» — только если ревизий нет. Персонал по графику — с V98.
