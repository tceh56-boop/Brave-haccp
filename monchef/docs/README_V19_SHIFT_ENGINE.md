# Mon Chef V19 — Shift Engine

V19 объединяет существующие V16/V17/V18 в единый экран смены.

## Что делает
- собирает HACCP-задачи оборудования;
- собирает производственные задачи;
- собирает HACCP-контроли, созданные из завершённого производства;
- сортирует очередь по срочности;
- отдельно выделяет просроченные и заблокированные задачи;
- показывает сводку выполнения смены;
- даёт шефу сводку по исполнителям;
- фиксирует открытие/закрытие смены без перезаписи исторических фактов.

## Экран
`?shift=1&token=SESSION_TOKEN` открывает `Shift.html`.

## Важно
V19 не подставляет измерения. Для HACCP сотрудник обязан ввести фактический показатель. Внутренние J-коды не показываются сотруднику как название журнала.

## Новые функции
- `getMyShiftDashboard(date, token)`
- `getChefShiftDashboard(date, token)`
- `startMyShift(json, token)`
- `endMyShift(json, token)`
- `runMonChefShiftCycle(token)`
- `installMonChefShiftTrigger(token)`
