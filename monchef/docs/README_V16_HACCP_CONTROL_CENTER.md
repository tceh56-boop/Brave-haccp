# Mon Chef V16 — HACCP Control Center

V16 связывает конкретное оборудование с автоматическими контрольными задачами.

## Что добавлено
- `HACCP_Оборудование`: холодильники, морозильники, складские зоны, фритюрницы и пользовательское оборудование.
- `HACCP_Задачи`: ежедневные экземпляры контрольных задач с дедлайном, фактом, сотрудником и отклонением.
- Автоматическое создание задач по существующему расписанию HACCP.
- Напоминания за 30 минут и уведомления о просрочке.
- Рабочий API `getHaccpControlCenter()` для экрана «Контроли сегодня».
- `completeHaccpEquipmentTask()` принимает фактическое значение и создаёт отклонение при выходе за пределы.
- Критическое отклонение дополнительно уведомляет шеф-повара.
- Настройка/редактирование оборудования через `upsertHaccpEquipment()`.
- Установка фонового цикла каждые 15 минут через `installMonChefHaccpControlCenterTrigger()`.

## Важно
V16 не подставляет измерения автоматически. Температура, результат проверки масла и другие фактические показатели вводятся сотрудником.

## Первичная установка
1. Выполнить `setupMonChefHaccpAutomation(token)` из V15.
2. Выполнить `seedMonChefHaccpEquipment(token)` один раз.
3. Выполнить `installMonChefHaccpControlCenterTrigger(token)`.
4. UI должен использовать `getHaccpControlCenter(token)` и `completeHaccpEquipmentTask(json, token)`.

Следующий этап: связать контрольные задачи с производственными событиями, партиями и FEFO, чтобы отдельные проверки автоматически возникали непосредственно из операции производства/охлаждения/разогрева.
