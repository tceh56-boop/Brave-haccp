# Mon Chef V14 — Weekly Operations

V14 возвращает фокус системы к главной задаче владельца: не пересчитывать банкеты, закупки и производство вручную.

## Что делает
- недельный контур Пн–Вс;
- все подтверждённые банкеты недели;
- автоматически считает блюда по ТТК;
- создаёт сводные производственные задачи на день до банкета;
- одинаковые блюда в один производственный день агрегируются;
- отдельно выявляет нехватку полуфабрикатов;
- рассчитывает сырьё для изготовления недостающих П/Ф;
- сравнивает потребность с остатками и минимальным запасом;
- формирует список позиций к закупке;
- записывает недельный план в `Недельный_План`;
- записывает производственные задачи в `План_Производства`;
- синхронизирует сводные задачи с существующей `Канбан_Задачи`;
- выполненные задачи канбана не удаляются;
- есть ручная кнопка «Пересчитать неделю»;
- предусмотрена автоматическая ежедневная проверка следующей недели.

## Важный принцип
ТТК, HACCP, журналы, OCR, склад, партии, FEFO, прослеживаемость и аудит не удаляются и не заменяются. V14 добавляет над ними слой оперативного планирования.

## Сценарий субботы
1. Все банкеты следующей недели уже сохранены/распознаны.
2. Руководитель открывает «Неделя».
3. Нажимает «Пересчитать неделю».
4. Mon Chef показывает банкеты, задачи производства, П/Ф в дефиците и закупку.
5. Производственные задачи появляются на доске за день до соответствующего банкета.
6. Закупка считается из ТТК + остатков + минимального запаса.
