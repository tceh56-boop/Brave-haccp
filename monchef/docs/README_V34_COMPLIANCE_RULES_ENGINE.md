# Mon Chef V34 — Compliance Rules Engine

V34 превращает нормативную матрицу V33 в исполняемые правила контроля.

## Архитектура
Норма → требование → правило → операционное событие → задача → факт/доказательство → покрытие → отклонение/корректирующее действие.

## Основные листы
- Правила_Контроля_V34
- Покрытие_Контролей_V34
- Задачи_Соответствия_V34
- Доказательства_V34

## Важный принцип
V34 не присваивает ГОСТ статус обязательной нормы автоматически. Обязательные требования отделены от методических рекомендаций. Текущая санитарная база общепита в релизе — СанПиН 2.3/2.4.4282-26 с 01.09.2026; ТР ТС 021/2011 остаётся обязательной базой для процедур безопасности пищевой продукции.

## События
RECEIVING_CONFIRMED, SHIFT_START, PRODUCTION_COMPLETED, SCHEDULE, BATCH_CREATED, CONTROL_COMPLETED.

## Интерфейс
?compliancerules=1&token=...

## Ограничения
Система не утверждает ППК за предприятие, не придумывает критические пределы и не заменяет фактический производственный контроль, лабораторные исследования, обучение персонала или юридически значимую подпись.
