# Mon Chef V98 — график смен сотрудников и нехватка персонала (24.11.2026)

Экран **«График смен»** (Главная, Настройки). Смены — расписание V89 («Сменные письма → Расписание смен»).

- Руководитель (task_assign, personnel) ставит сотрудника в смену или своё время; конфликт по времени — отказ; «Повторить эту неделю на следующую».
- **Отсутствие** — причина из списка (отпуск, отгул, уважительная, без причины, другое) — **без медицинских подробностей**.
- **Норма персонала** по роли и смене площадки задаёт руководитель **с основанием** (штатное расписание, приказ) — система норму не придумывает; нет нормы — «нет нормы».
- **Потребность поваров по прогнозу**: пик спроса по часам тех же дней недели площадки / норма выработки («Прогнозы → Правила»); меньше 3 наблюдений — НЕТ ДАННЫХ.
- Предупреждения: сотрудник в двух сменах, неактивен, пищевая роль без действующего допуска (только статус допуска).
- Нехватка — в «Моей смене» руководителя и в реестре рисков V93 (STAFF_SHORTAGE по смене); сотрудник видит «Мои смены». ФОТ и табель не рассчитываются.
