# Mon Chef V42 — Санитария: задачи, растворы, контроль, остатки

## Цель
V42 переводит справочник V41 в операционный контур кухни:

`утверждённый режим → санитарная задача → выполнение → FACT → контроль раствора → отклонение → alert → остаток/закупка`

## Что изменено
- `Санитария_Зоны_V42` — зоны/участки кухни;
- `Санитария_Планы_V42` — плановые санитарные задачи;
- `Санитария_Выполнение_V42` — фактическое выполнение;
- `Санитария_Контроль_V42` — фактический контроль концентрации;
- `Санитария_Остатки_V42` — партии/остатки концентратов;
- `Санитария_Алерты_V42` — просроченные растворы, низкий остаток, отклонения.

## Жёсткие ограничения
1. Режим должен быть `APPROVED` в V41.
2. Средство должно иметь `AllowedForCatering = YES` и `ApprovalStatus = APPROVED`.
3. V42 не придумывает концентрацию/экспозицию.
4. Если строка режима не позволяет надёжно разобрать числовой диапазон, результат контроля остаётся `REVIEW`, а не автоматически `OK`.
5. Медицинские/ЛПУ режимы не становятся кухонными только потому, что они есть в исходном справочнике.

## Важное ограничение текущего этапа
Проверка `AllowedForCatering` и `APPROVED` — это внутренний workflow Mon Chef, а не юридическое доказательство государственной регистрации средства. Для юридически значимого утверждения нужны реквизиты и документы конкретного препарата.
