# Mon Chef V55–V63 — Production Release Stack

Этот пакет переводит разработку от добавления отдельных модулей к производственному контуру.

## V55 — migration bridge
- нормализация ProductID/ресурсов;
- аудит миграции;
- физический остаток не изменяется.

## V56 — unified production order
- ProductionOrderID;
- банкет/TTK/продукт/количество/срок/цех;
- частичное и полное завершение.

## V57 — weekly dispatcher
- единый список производственных заказов;
- риск и остаточный дефицит.

## V58 — end-to-end banquet test run
- контрольные стадии от заказа до закрытия;
- тест не подменяет фактическую операцию.

## V59 — HACCP operational bridge
- связь операции с ожидаемым HACCP/CCP фактом;
- незакрытые ожидания видны отдельно.

## V60 — server-side authorization/audit
- проверка роли на сервере;
- аудит ALLOW/DENY.

## V61 — structural test harness
Проверяет наличие критических production-компонентов.

## V62 — pilot plan
Стадии: master data → stock → production → banquet → HACCP → parallel run → go-live.

## V63 — release gate
Автоматически проверяет структурные тесты, миграцию, пилотный план и отсутствие незакрытых V59 ожиданий.

### Важно
V63 — release gate, а не юридическая сертификация и не доказательство соответствия СанПиН. Для реального запуска требуется прогон на фактических данных, резервное копирование, восстановление и приёмочные испытания на площадке.
