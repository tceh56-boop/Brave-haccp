Ветка `claude/restaurant-service`. Бар — производственное подразделение внутри MON CHEF: **без своего склада и без своих ТТК** (ТЗ §9, §18 п. 3, 5).

## 1. Роли (ТЗ §8)

| Роль | По умолчанию | Запрещено по умолчанию |
|---|---|---|
| **Бармен** | меню и ТТК (просмотр), задания бара, заготовки бара (план, начать, выпустить), использование партий, остатки (просмотр), маркировка, чек-листы, Stop/Go бара | себестоимость и закупочные цены, утверждение ТТК, экономика, сотрудники и права, задания кухни |
| **Менеджер бара** | всё, что у бармена, + контроль бара (`bar_manage`), управление производством, склад, планирование, снятие «на проверке», история ТТК, просмотр зала | себестоимость — только по праву от директора |

* Обе роли — роли кухни для медицинского допуска: без действующей медкнижки задания бара не ведутся.
* Цех ролей — «Бар» (право `shop_bar`).
* Права настраивает директор в редакторе ролей. Индивидуально можно выдать: менеджеру бара — себестоимость и заказы поставщикам, обоим — приёмку.

## 2. Барные рецептуры (ТЗ §9.1)

* Это обычные ТТК MON CHEF с цехом «Бар» в листе «Блюда». Группы (коктейли, кофе, сиропы, кордиалы, настойки…) — категория блюда.
* Вкладка «Рецептуры бара» показывает только то, что есть в утверждённой версии ТТК:
  * состав: количество, единица, брутто → нетто и процент потерь;
  * выход, технология, версия;
  * условия и срок хранения — из `ТТК_Версии`.
* Нет утверждённой версии — показано красным.
* Оборудование в ТТК MON CHEF не ведётся, поэтому показано «не указано в ТТК» — система его не придумывает.
* Себестоимость порции (нормативная, V64) — только с правом `costs`.

## 3. Заготовки бара (ТЗ §9.2)

Сырьё → производственная операция → заготовка → партия → хранение → использование → списание. Всё идёт через **существующее производство MON CHEF**:
- `planProduction` → `startProduction` → `completeProduction`;
- сырьё списывается по партиям FEFO;
- создаётся партия заготовки;
- проверяются обязательные ККТ, выполняется бракераж, сохраняется прослеживаемость.

**Срок годности:** по правилам сроков MON CHEF или с документа — система его не придумывает. Если правил для заготовки нет, срок остаётся пустым и это видно.

Вкладка «Заготовки бара»: выбрать полуфабрикат цеха «Бар» (название с «п/ф» и составом в ТТК) → «Запланировать» → «Начать» → «Выпустить» (фактический выход, при необходимости срок с документа).

**Закрыта дыра в существующем коде.** Раньше любой сотрудник с правом «канбан» мог через API запустить или выпустить производственное задание чужого цеха — сервер цех не проверял. Теперь цех проверяется при плане, старте, выпуске и отмене (`Code.gs`). Повар горячего цеха больше не выпустит заготовку бара, бармен — кухонный полуфабрикат.

## 4. Приготовление напитка (ТЗ §9.3) — и блюда тем же механизмом

* На карточке задания бармен видит **рецепт**: состав на порцию (нетто — сколько идёт в бокал) и технологию.
* **«Готовить»** — проверка наличия партий без списания. Если чего-то не хватает, бармен видит предупреждение сразу.
* **«Готово»** — списание ингредиентов по действующей ТТК движком MON CHEF V71:
  * порядок: готовые допущенные партии → полуфабрикаты (например, сироп) → сырьё, по FEFO;
  * со склада уходит брутто ТТК;
  * себестоимость считается по партиям и записывается в задание;
  * создаются связи прослеживаемости «партия → позиция заказа»;
  * складская операция подписана «Производство заказа <задание>».
* **Без двойного списания:** найдена такая подпись — повтор не списывает.
* **Нехватку не досписываю «из воздуха»:** остаток уменьшается только на реально списанное, недостача записана в задание, бармен видит предупреждение, менеджеру бара (на кухне — шеф-повару) приходит уведомление.
* Весовое блюдо списывается пропорционально весу: вес ÷ выход ТТК.
* Тот же механизм работает и на кухне: «Готово» на кухне тоже списывает по ТТК.
* **Отмена:**
  * отмена с полным расходом проводится по складу сразу; если уже списано при «Готово» — второй раз не списывается;
  * частичный расход — актом списания MON CHEF по описанию: количества система не угадывает.

Отдельного склада бара нет — общий склад `Склад_Партии`. Место хранения и площадка — механизмом V97.

## 8. Ограничения

* Срок годности заготовки — только по правилам сроков MON CHEF или с документа. Если правил нет, срок пуст: правила заводят в «Сроки годности» (V38–V40).
* Себестоимость в задании — по партиям на момент приготовления. Выручка, food cost и сверка с Z-отчётом — этап 7.
* Оборудование барных рецептур в ТТК не ведётся; если нужно — это доработка карточки ТТК, отдельной задачей.
* Проверено на стенде; перед пилотом — копия рабочей таблицы с реальными партиями.
