# Mon Chef V96 — справочник продуктов: производитель, штрихкод, статус, разбор групп (24.11.2026)

Экран **«Справочник продуктов»** (Склад, Меню и ТТК).

- Карточка каждой строки базы продуктов («Продукты_Справочник»): единица (г, кг, мл, л, шт, уп — вносит человек, система не придумывает), **производитель**, **штрихкод** (EAN-8, UPC-A, EAN-13, GTIN-14 с проверкой контрольной цифры; один штрихкод — одна действующая карточка), **статус** (действует / на проверке / объединена / в архиве — с причиной), вид (сырьё / полуфабрикат). История изменений, аудит. Строки базы не удаляются.
- **Группы на разбор** строятся тем же алгоритмом, что в аудите справочника (ДОК_12, П2): на присланной базе — те же **318 групп** (52 «одинаковое название, разный тип», 5 точных дублей, 29 похожих названий, 98 марок/латиницы, 134 полуфабриката). Проверено на стенде: группировка совпала с аудитом без расхождений.
- У каждой группы — почему и предложение; решает человек с правом «ttk_approve» или «stock» (галочка): объединить (оставить одну позицию; сопоставления ТТК и склада V53 переходят на оставленную), оставить раздельно (с пояснением), полуфабрикат / сырьё, марка (производитель), название верное, в архив. Пачкой — до 100 групп одним решением без выбора позиции.
- Решённые группы при пересборке не возвращаются; изменившиеся — «справочник изменился». Поиск по штрихкоду — для приёмки и склада.
- **318 групп система за вас не разбирает**: решения — за ответственным.
