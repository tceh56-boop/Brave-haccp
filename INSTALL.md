# ЦЕХ — установка на Google Диск

Таблица-БД: https://docs.google.com/spreadsheets/d/1lm5j3aMf-uXFy3PXutcEluqG7uRtoMwOPXdpIWT18qY/edit
(папка «ЦЕХ HACCP» на Диске).

1. Включите Apps Script API: https://script.google.com/home/usersettings → «Google Apps Script API» → Вкл.
2. Откройте таблицу → **Расширения → Apps Script**.
3. **Настройки проекта** (шестерёнка) → отметьте «Показывать файл манифеста appsscript.json».
4. В редакторе замените содержимое `appsscript.json` на `install/appsscript.json`,
   а содержимое `Код.gs` — на `install/Installer.gs`. Сохраните.
5. Выберите функцию `installTsekh` → **Выполнить** → разрешите доступ.
   В журнале должно появиться «Установлено файлов: …».
6. Обновите страницу редактора. Выберите `setupProduction` → **Выполнить**.
   В журнале будет PIN первого директора — сохраните его.
7. Запустите `deployPreflight` и проверьте, что нет FAIL.
8. Запустите `installTriggers` (см. ограничение ниже).
9. **Начать развёртывание → Новое развёртывание → Веб-приложение**
   (запуск от: «Я», доступ: «Только я» — как в манифесте) → откройте полученный URL.

## Ограничение

Apps Script разрешает не больше 20 триггеров на проект, а `installTriggers()` создаёт 28.
На 21-м триггере функция упадёт с ошибкой — первые 20 будут созданы, остальные нет.
