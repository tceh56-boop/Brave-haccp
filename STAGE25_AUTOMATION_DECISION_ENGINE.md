# ЦЕХ CORE100 — Stage 25: Automation & Decision Engine

## Контур
Сигнал → предложение → согласование → выполнение → аудит.

## Автоматически
- Control Tower формирует предложения только для CRITICAL/HIGH сигналов.
- Дедупликация по организации/точке/source_code.
- TTL предложения: 24 часа.
- Триггер работает раз в 2 часа.

## Только после подтверждения
Разрешены два действия: `CREATE_TASK`, `CREATE_PURCHASE_REQUEST`.
В Stage 25 автоматически исполняются только предложения `CREATE_TASK`; закупочные предложения зарезервированы контрактом для следующего расширения, чтобы не создавать финансовых обязательств без отдельного правила и UI.

## Безопасность
- `APPROVE_AUTOMATION_DECISION` и `REJECT_AUTOMATION_DECISION` требуют модуль `automation_approve`.
- Модуль выдан ДИРЕКТОРУ и ADMIN.
- Предложение проверяет organization/location scope.
- Повторное согласование не исполняет действие второй раз.
- Истёкшие предложения нельзя исполнить.
- Ошибка выполнения переводит решение в `FAILED`.
- Все действия аудируются.

## Миграция
`runAllMigrations()` создаёт/дополняет лист `AUTOMATION_DECISIONS`.

## UI
Dashboard содержит список PENDING предложений с кнопками «Согласовать»/«Отклонить» только для роли с `automation_approve`.
