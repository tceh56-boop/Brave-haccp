# QR-меню ЦЕХ — отдельное публичное приложение

Гости открывают меню по QR-коду на столе без входа. Основное приложение ЦЕХ остаётся
закрытым («только я»): это маленький **отдельный** проект Apps Script с доступом «Все».
Он только читает лист `PUBLIC_MENU` той же таблицы — снимок меню без себестоимости,
поставщиков и сотрудников, который каждые 15 минут обновляет ЦЕХ.

## Установка (один раз, ~5 минут)
1. Откройте https://script.google.com → **Новый проект**. Назовите его, например, «ЦЕХ — QR-меню».
2. **Настройки проекта** (шестерёнка) → отметьте «Показывать файл манифеста appsscript.json».
3. Замените содержимое `appsscript.json` на файл `qrmenu/appsscript.json`,
   а содержимое `Код.gs` — на `qrmenu/Code.gs`. Сохраните.
4. **Настройки проекта → Свойства скрипта → Добавить свойство**:
   `SPREADSHEET_ID` = ID таблицы ЦЕХ (часть адреса таблицы между `/d/` и `/edit`).
5. **Начать развёртывание → Новое развёртывание → Веб-приложение**:
   запуск от «Я», доступ «Все». Разрешите доступ (только чтение таблиц).
6. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
7. В ЦЕХ: **Касса и зал → QR-меню** → вставьте адрес → «Сохранить» → «Опубликовать меню сейчас».
8. Там же — «Печать QR столов»: у каждого стола свой код (меню показывает номер стола).

## Что видит гость
Название заведения, категории, блюда с ценой, выход, аллергены и пищевую ценность из
утверждённой ТТК, варианты модификаторов с надбавками. Блюда в стоп-листе скрыты.
Заказать с телефона нельзя — только посмотреть и позвать официанта.

## Безопасность
- Права проекта — только чтение таблиц (`spreadsheets.readonly`); код открывает один лист.
- Ссылка содержит случайный ключ точки (`?m=…`); выключить меню точки можно в ЦЕХ.
- Ключ не меняется при обновлении меню, поэтому напечатанные QR продолжают работать.
