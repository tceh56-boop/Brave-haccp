# Проверка генерации ППК в ЦЕХ: что нажимается, что появляется, что создаётся

Прогон в Chromium на настоящих модулях ЦЕХ (Ppk, PpkGenerator, PpkDocuments, ТТК, рецептуры, журналы).
Исходные данные: ООО «Студия Вкуса», точка «Лофт», горячий и холодный цех, пароконвектомат и холодильный
шкаф, поставщик, ТТК «Французская котлета» с ПФ «Сливочный ризотто» и «Сырный ролл с каперсами»
(импорт из архива), 21 продукт, 15 строк рецептуры. Роль — ТЕХНОЛОГ_HACCP.

## Найдено и исправлено в ходе проверки

1. **До первой утверждённой ППК модель черновика не открывалась.** Дашборд висел на «Загрузка…», «Карта
   потоков» и «Документ ППК» давали ошибку «нет/чужой: PPK_VERSIONS»: экран искал только утверждённую
   версию. Теперь экран работает с последним черновиком/версией на согласовании, иначе — с утверждённой
   (`getWorkingPpk_`); ошибка дашборда показывается текстом.
2. **Кнопки «На согласование» и «Утвердить» не работали:** номер версии передавался с лишними кавычками
   (`"PPK_VERSIONS-73"`) — сервер версию не находил. Та же ошибка была у кнопки инструктажа по охране
   труда («Открыть»). Исправлено во всех трёх местах.

## Чего в интерфейсе нет (довести ППК до утверждения с экрана сейчас нельзя)

* **Подтверждение анализа опасностей** — сервер умеет (`CONFIRM_PPK_HAZARD`: вероятность, тяжесть,
  мера контроля, классификация PRP/ППОПМ/КТ/ККТ, предел, мониторинг, ответственный, корректирующее
  действие), кнопок нет. 44 заготовки без подтверждения блокируют утверждение.
* **Подтверждение контрольных точек и критических пределов** (`CONFIRM_PPK_CONTROL`,
  `CREATE_PPK_CRITICAL_LIMIT`, `APPROVE_PPK_CRITICAL_LIMIT`) и **генерация журналов**
  (`GENERATE_PPK_JOURNALS`) — кнопок нет. Обходной путь сейчас — только ККТ из ТТК (шаг 4 прошлых
  этапов), он добавляет подтверждённые контроли, но опасности всё равно блокируют.
* **Документ** — нет читаемого вида, печати и PDF: «Документ ППК» выводит JSON. Сервер умеет PDF
  инспекционного пакета (`GENERATE_PPK_INSPECTION_A4_PDF`), но кнопки нет. Многие разделы пустые
  (`Ответственные лица`, `Организация производства`, `Общие положения`) — их нечем заполнить.
* **Анализ опасностей — заготовка**, не анализ: одинаковые 4 строки на каждый этап, без связи с
  продуктами, нормами (`TECH_NORMS`) и ККТ из ТТК.
