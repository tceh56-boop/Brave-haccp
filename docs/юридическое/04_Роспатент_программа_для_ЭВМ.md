# Регистрация программы для ЭВМ «ЦЕХ» в Роспатенте

> **Черновик.** Регистрация добровольная (ст. 1262 ГК РФ). Она подтверждает авторство и дату и нужна для включения в реестр российского ПО. Актуальные требования к заявке и размер пошлины проверьте на сайте Роспатента (rospatent.gov.ru) перед подачей. Подача — онлайн через сайт Роспатента или Госуслуги.

## Состав заявки

1. **Заявление** по форме Роспатента. Заполняется на сайте.
2. **Депонируемые материалы** — фрагмент исходного текста, по которому можно опознать программу: первые и последние 25 страниц. Готовый файл: `роспатент/депонируемые_материалы_исходный_текст.pdf`. Пересобирается командой `npm run legal:listing`, всего 50 листов.
3. **Реферат** — ниже.
4. **Документ об уплате пошлины.**

## Реферат

**Название:** «ЦЕХ» — система управления предприятием общественного питания.

**Правообладатель / автор:** Слепцов Денис Владимирович.

**Аннотация:** Программа предназначена для предприятий общественного питания и обеспечивает:
- производственный контроль и систему ХАССП: замеры по утверждённым правилам, отклонения, корректирующие действия (CAPA), план ХАССП с деревом решений;
- журналы J01–J53 с неизменяемыми записями и подписью за период;
- приёмку сырья с проверками, учёт партий и сроков годности (FEFO), технологические карты с себестоимостью и пищевой ценностью;
- кассу и учёт продаж со списанием сырья;
- нормативный реестр и пакет документов для проверки.

Работает через веб-браузер с телефона, планшета или компьютера. Данные организаций изолированы, действия пользователей фиксируются в журнале аудита, защищённом цепочкой хешей.

**Тип ЭВМ:** IBM PC-совместимый сервер; клиент — любое устройство с современным веб-браузером.
**Язык:** TypeScript, SQL (PostgreSQL), CSS.
**ОС:** Linux (сервер); клиент — любая ОС с браузером.
**Объём исходного текста:** около 963 КБ (248 файлов). Точные значения — в `роспатент/сведения_для_реферата.json`.

## Полезно знать

- Справочник продуктов и архив ТТК — ваши данные. При желании их можно зарегистрировать отдельно как **базу данных** (ст. 1260 ГК РФ), это та же процедура.
- После регистрации номер свидетельства указывают в договоре-оферте и в заявке в реестр российского ПО (reestr.digital.gov.ru).
