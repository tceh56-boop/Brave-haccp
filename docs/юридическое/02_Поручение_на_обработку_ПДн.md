# Приложение 1 к лицензионному договору. Поручение на обработку персональных данных

> **Черновик для юриста.** Поручение по ч. 3 ст. 6 Федерального закона № 152-ФЗ «О персональных данных». Состав данных и меры защиты описаны по фактическому устройству системы «ЦЕХ».

**Оператор** — Лицензиат. **Обработчик** — Лицензиар. Акцептуя Договор, Оператор поручает Обработчику обработку персональных данных на условиях ниже.

## 1. Цель обработки

Обеспечение работы Системы для Оператора: вход пользователей, подписание записей производственного контроля и учёта именем сотрудника, разграничение прав, уведомления, хранение и резервное копирование данных.

## 2. Субъекты и перечень данных

| Субъекты | Данные | Где в Системе |
|---|---|---|
| Работники Оператора и иные лица, допущенные Оператором (пользователи) | фамилия, имя, отчество; адрес электронной почты; должность и роль в Системе; хеш пароля (сам пароль не хранится) | учётные записи |
| Пользователи | IP-адрес, сведения об устройстве и браузере, время входа и выхода, неудачные попытки входа | сессии, журнал входов |
| Пользователи | действия в Системе: что, когда, с какого IP-адреса; ФИО в записях журналов, отклонений, CAPA, приёмок, кассовых смен | журнал аудита, записи операций |
| Лица, которых Оператор пригласил | ФИО (если указано), email | приглашения |
| Лица на фотографиях, загруженных Оператором как доказательства (если попали в кадр) | изображение | файлы-доказательства |

Специальные категории (ст. 10) и биометрические данные (ст. 11) Система для обработки не предназначена. Оператор не загружает такие данные в Систему.

## 3. Действия с данными

Сбор (через интерфейс Системы), запись, систематизация, накопление, хранение, уточнение, извлечение, использование, блокирование, удаление, уничтожение. Обработка автоматизированная.

Обработчик **не передаёт** данные третьим лицам, кроме следующих субподрядчиков, без которых работа Системы невозможна:

| Субподрядчик | Что делает | Где |
|---|---|---|
| ООО «Яндекс.Облако» (Yandex Cloud) | вычислительные ресурсы, хранение базы данных и резервных копий | центры обработки данных на территории РФ |
| [Почтовый сервис: Яндекс 360 для бизнеса / Yandex Cloud Postbox] | отправка служебных писем (приглашение, подтверждение email, сброс пароля) | территория РФ |

О смене субподрядчика Обработчик уведомляет Оператора не менее чем за [30] дней.

## 4. Локализация

Запись, систематизация, накопление, хранение, уточнение и извлечение персональных данных граждан РФ осуществляются с использованием баз данных, находящихся на территории РФ (ч. 5 ст. 18 152-ФЗ). Трансграничная передача не осуществляется.

Функция AI-помощника по умолчанию **отключена**. Её включение возможно только по отдельному письменному согласованию с Оператором. В этом случае Обработчик предварительно описывает, какие данные передаются: фамилии, имена и email пользователей во внешний сервис не передаются, передаются только данные отклонения и тексты требований.

## 5. Меры защиты (ст. 18.1, 19 152-ФЗ)

Обработчик обеспечивает:

1. **Разграничение доступа.** Права проверяются на сервере для каждого действия по роли пользователя и площадке. Данные разных организаций изолированы на уровне базы данных (row-level security). Сотрудники Обработчика получают доступ к данным Оператора только для поддержки по его обращению или для восстановления после сбоя.
2. **Аутентификация.** Пароли хранятся только в виде хеша (scrypt). Ссылки и сессии хранятся как хеши токенов. После 5 неверных паролей вход блокируется на 15 минут. Сессия отзывается при смене пароля.
3. **Защита каналов.** Доступ только по HTTPS (TLS), включён HSTS.
4. **Регистрация событий.** Журнал аудита ведётся только на дописывание и защищён цепочкой хешей SHA-256: изменение или удаление записей обнаруживается.
5. **Резервное копирование.** Ежедневная копия с автоматической проверкой восстановления, хранение в объектном хранилище в РФ.
6. **Обновления.** Система и её компоненты своевременно обновляются, известные уязвимости устраняются.
7. **Учёт машинных носителей и физическая защита** обеспечиваются центром обработки данных субподрядчика.
8. Уровень защищённости персональных данных — [УЗ-4] (Постановление Правительства РФ № 1119). *Определить с юристом по составу данных и угрозам.*

## 6. Обязанности Обработчика

1. Обрабатывать данные только по поручению и в целях раздела 1.
2. Соблюдать конфиденциальность.
3. По запросу Оператора в течение [5] рабочих дней предоставлять сведения, необходимые для ответа субъекту (ст. 14). Каждый пользователь может сам выгрузить сведения о себе: «Управление → Мои данные».
4. Уведомлять Оператора об инциденте с персональными данными не позднее [24 часов] с момента обнаружения, чтобы Оператор мог исполнить обязанность по ч. 3.1 ст. 21 152-ФЗ.
5. По окончании Договора — передать данные Оператору (выгрузка) и уничтожить их в сроки раздела 8 Договора, подтвердив уничтожение актом.

## 7. Обязанности Оператора

Обеспечить законное основание обработки (в том числе для работников — в рамках трудовых отношений), уведомить субъектов, при необходимости получить согласия, выполнить обязанность по уведомлению Роскомнадзора (ст. 22), назначить ответственного за организацию обработки.
