# Инструкция для персонала — сборка

Инструкция собирается из настоящей системы: все `.gs` загружаются в эмулятор Apps Script
(таблица, кэш, свойства — в памяти), настоящий `gas/Index.html` открывается в Chromium.

1. `gasemu.js` — эмулятор Apps Script; `seed.js` — организация, точка и сотрудники по ролям
   (`seedUatData()`); `demo.js` — демо-данные через настоящие действия API: ТТК, поставщики,
   приходы, производство, мастер ППК и утверждение ППК, журналы, задачи, лаборатория,
   банкет, продажи, инвентаризация.
2. `tour.js` — обход разделов под нужными ролями, оранжевые рамки с номерами, снимки в `shots/`.
   Внешние сервисы на стенде отключены. Распознавание накладной подменено ответом для
   демо-накладной, QR этикеток рисуется локально.
3. `content.js` — текст инструкции; номера шагов соответствуют номерам на снимках.
   `build.js` — вёрстка A4 и PDF в два прохода, чтобы в содержании были номера страниц.

```
npm install            # playwright, qrcode
npx playwright install chromium   # если браузера ещё нет
npm run manual         # снимки + PDF в docs/ЦЕХ_инструкция_для_персонала.pdf
```

После изменения интерфейса пересоберите инструкцию. Если кнопка переименована, `tour.js`
напишет «!! не найдено» с её описанием — поправьте метку и текст шага в `content.js`.
