# Mon Chef V72 — унифицированные формы ОП (постановление Госкомстата России № 132)

ОП-3, ОП-7, ОП-10, ОП-11, ОП-12, ОП-18, ОП-21, ОП-23 строятся системой из учёта. Формы набраны заново по постановлению: без логотипов, ссылок и рекламы сторонних сайтов.

## Файлы
| Файл | Что делает |
|---|---|
| `MonChef_V72_OpForms.gs` | сбор данных по формам, цены, сумма прописью, HTML форм, реестр документов (номер, снимок данных, PDF), аннулирование, нормы выхода ОП-23 |
| `MonChef_OrgSettings.gs` | новые поля реквизитов: ОКПО (с контрольным числом), ОКВЭД 2 |
| `Console.html` | экран «Документы ОП: унифицированные формы» (Склад, Документы, Отчёты) |
| `MonChef_Rbac.gs`, `MonChef_V69_UI.gs`, `zzz_MonChef_Gate.gs` | права и кнопки разделов |

## Откуда данные
| Форма | Данные | Цены |
|---|---|---|
| ОП-3 | сырьё, списанное за день: выпуск (TRACE_LINKS «РАСХОДОВАНА_НА»), продажа под заказ (V71), обработка сырья (Разбор_Акты); по цехам; п/ф и блюда своего производства не входят | — |
| ОП-7 | ОП-3 за день из реестра | учётные — по ценам партий |
| ОП-10, ОП-11 | журнал продаж: зал, выдача банкетов; акты «Питание персонала» | продажа — из журнала; сотрудникам — «Цены меню»; учётная — себестоимость порции |
| ОП-12 | продажи в зал | фактические и учётные |
| ОП-18 | остатки по партиям на момент формирования; тара — позиции норм упаковки | средняя цена партий |
| ОП-21 | акты «Питание персонала» | отпускная — «Цены меню»; учётная — стоимость акта |
| ОП-23 | акты разбора и зачистки за период | сырьё — цена партии; выход — стоимость сырья по массе |

Учётная цена производства: по партиям, списанным при продаже → по последнему выпуску → по нормативу ТТК.

## Правила
- Организация, объект, ОКПО, ОКВЭД — из реквизитов; руководитель — ответственное лицо; заведующий производством — шеф-повар (если он один).
- Чего в системе нет — поле пустое и пояснение (подписи, выручка кассы, специи и соль, цены продажи сырья, нормы выхода без основания).
- Сформированный документ: номер по форме и году, снимок данных (`Документы_ОП_V72`), PDF в папке «Документы ОП (унифицированные формы)». Аннулирование — с причиной, номер не переиспользуется.
- Нормы выхода ОП-23 (`Нормы_Выхода_Разделки_V72`) — только с основанием.
- Права: смотреть и формировать — «Склад» или «Экономика — просмотр» (шеф-повар, директор); аннулировать — «Склад» или «Закрытие периода»; технический доступ документы не формирует.
