# Mon Chef V77 — бракераж по продажам одним нажатием (17.11.2026)

Основание — ваше поручение «Бракераж, автоматизировать продажей» (после замечания, что система сложна для повара).

## Что изменилось для шеф-повара
- На главном экране первая кнопка — **«Бракераж: ждут N»** (или «Бракераж: всё оценено»), плитка **«Продано без бракеража»**. Та же кнопка — в разделе «Производство».
- Экран **«Бракераж»** собран из журнала продаж:
  - **«Продано сегодня без бракеража»** — блюда по ТТК, проданные сегодня под заказ, по которым оценки сегодня нет: порции и время первой продажи;
  - **«Обычно продаётся»** — блюда, проданные за прошлые 7 дней: оценить до начала продаж;
  - **«Оценено сегодня»** — кто и когда оценил; оценка позже первой продажи — с отметкой «после первой продажи».
- **«✓ Соответствует»** → вопрос «вы сами оценили блюдо?» → строка журнала бракеража J02 той же проверкой, что форма: внешний вид, вкус, запах — «соответствует», решение «Отпуск разрешён», бракер — вошедший сотрудник, повар — по выбору из действующих сотрудников. «Все N — соответствуют» — для нескольких блюд сразу.
- **«Замечания»** открывают обычную форму бракеража с подставленным блюдом: описание и решение вводит человек.

## Чего система не делает
Органолептику и решение не подставляет без человека: строка появляется только после нажатия и подтверждения (`confirm: true`), иначе — отказ «Подтвердите, что оценили блюдо сами». Повторное нажатие в тот же день — «уже оценено», второй строки нет. Неизвестное блюдо, повар не из действующих, технический доступ — отказ.

## Какие продажи учитываются
Строки листа `Продажи_Списание_V71` вида «блюдо по ТТК». Блюда, проданные **из готовых партий производства**, оцениваются по партии (строка J02 появляется при выпуске) и в список «под заказ» не попадают. Оценка партии производства не считается оценкой блюда под заказ.

## Права
- **Смотреть:** «Бракераж», «ХАССП», «ХАССП — просмотр».
- **«Соответствует»:** «Бракераж» — директор, шеф-повар, ответственный за ХАССП; повару и кондитеру — по индивидуальному праву (ДОК_2, раздел 3). Технический доступ записей не делает (TECH_NO_HACCP_RECORDS).
- Нажатия — в журнале аудита (BRAKERAGE_QUICK).

## Листы
Новых нет: пишется журнал `Ж_Бракераж_Готовой_Продукции` (J02), читается `Продажи_Списание_V71`.

## Ограничения
- Продажи в зале пока вводятся вручную (журнал продаж). Загрузка продаж за смену документом или подтверждение всего списка — следующий шаг (V79).
