# Mon Chef V73 — КБЖУ с источником и статусом; исправления по нормативному аудиту (16.11.2026)

Основание — нормативный аудит (ДОК_12) и ваше поручение «перейди к исправлениям в системе» со справочником «Химический состав российских пищевых продуктов» (под ред. И. М. Скурихина и В. А. Тутельяна, Институт питания РАМН, 2002).

## КБЖУ
- **Лист `КБЖУ_Значения_V73`**: значение на 100 г или 100 мл — ккал, белки, жиры, углеводы, пищевые волокна, сахара, соль. Для каждого значения хранятся: способ получения, источник, таблица / код, страница, проверка энергии, кто внёс, кто и когда проверил, статус.
- **Способ получения**, в порядке доверия: лабораторный протокол → спецификация производителя → маркировка → техническая документация → справочные таблицы → расчёт по рецептуре → неподтверждённое значение.
- **Статусы**: черновик → на проверке → утверждено; отклонено; заменено. Неподтверждённое значение — только черновик. Утверждает ответственный за ХАССП или шеф-повар, и не автор записи. Если энергия не сходится с 4 × Б + 9 × Ж + 4 × У — утверждение только с пояснением.
- **Расчёт.** В КБЖУ блюда, карточку и этикетку идут **только утверждённые** значения. Не хватает значения — «КБЖУ не определено», на этикетке КБЖУ нет; пустое значение не считается нулём.
- **Справочник.** 1009 строк на 100 г съедобной части с таблицей, кодом и страницей. Строки извлечены из DjVu по координатам; взяты только те, у которых энергия книги сходится с её же методикой (табл. А: белки 4,0, жиры 9,0, углеводы 4,0 ккал/г, органические кислоты ~3). 89 строк не прошли проверку — их нужно ввести вручную (ДОК_12, приложение П8). Значение из справочника — справочное, а не подтверждение состава продукта поставщика.
- **Миграция, шаг 11.** Прежние значения («Справочник_Пищевая_Ценность», 58 значений в коде, сопоставления с базой продуктов) — в черновики.

## Прочие исправления
- **Сроки «по категории блюда»** («Салаты — 6 ч», иначе 12 ч) больше не ставятся: нет срока в карте и в утверждённой таблице сроков — «СРОК РЕАЛИЗАЦИИ НЕ УКАЗАН» (ГОСТ 30390-2013, п. 5.7).
- **Приход.** Срок по справочнику продуктов (матрица) записывается в паспорт партии с пометкой «значение не утверждено — сверьте с маркировкой».
- **Аллергены.** Добавлены «аспартам и аспартам-ацесульфамовая соль» (перечень ТР ТС 022/2011 на сайте ЕЭК — 15 позиций).
- **Реестр нормативов** (миграция, шаг 12):
  - ГОСТ Р 51705.1-2001 — заменён;
  - добавлены ГОСТ Р 51705.1-2024, СП 2.3.6.4281-26, приказ Минздрава № 29н, приказ Минсельхоза № 862.
- **Товары.** При импорте из базы продуктов в поле «единица» больше не попадает «UNKNOWN» от типа продукта (миграция, шаг 13).
- **Удалено.** Неиспользуемые «режимы холодильников по умолчанию» (без источника).
