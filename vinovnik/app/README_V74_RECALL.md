## Как работает
1. **Порядок отзыва предприятия** (назначает директор):
   - ответственные за отзыв — из действующих сотрудников;
   - орган контроля и контакты;
   - порядок и сроки уведомлений;
   - периодичность учебного отзыва;
   - место изоляции по умолчанию;
   - срок хранения записей.

   Кнопка «Порядок отзыва (PDF)» формирует документ «Порядок изъятия (отзыва) продукции» (п. 8.9.5 a–c). Незаполненное в нём отмечено «задаёт предприятие».
2. **Назначенные ответственные.** Если они назначены, реальный отзыв открывают, решают, закрывают и отменяют только они и директор. Не назначены — работают права ролей, а экран предупреждает. Учебный отзыв проводят и другие сотрудники с правами.
3. **Охват:** номера партий или продукт с уточнением (поставщик, изготовитель, партия изготовителя, даты приёмки). Продукт без уточнения — отказ.
4. **Несоответствие** выбирается из списка по 29-ФЗ ст. 3 п. 2, категория «опасная» или «некачественная» записывается в отзыв.
5. **Прослеживание вперёд** только по связям движения продукции: производные п/ф и блюда, продажи, банкеты, акты, отходы, возвраты, пробы. Баланс партии: получено = остаток + прослеженное выбытие (п. 8.3).
6. **Блокировка сразу при открытии** — своя запись, прежний статус запомнен. Её не снимают лаборатория, бракераж и общее «снять блокировку».
7. **Решение по каждой партии** (фиксируется, кто санкционировал, с должностью):
   - **возврат поставщику** — с документом;
   - **ликвидация по акту** — уничтожение (8.9.4.3 c) или другое назначение (8.9.4.3 b). При микробиологическом, химическом, физическом несоответствии без записи об обеззараживании акт не проводится. Экспертиза (29-ФЗ ст. 25 п. 1) — поле для документа;
   - **снятие с отзыва** — только с основанием выпуска (партия не затронута; анализ подтверждает соответствие — 8.9.4.2 c; иное свидетельство — 8.9.4.2 a, b; переработана — 8.9.4.3 a) и документом.
8. **Уведомления и ответы.** Поставщик, орган контроля (по предписанию), заказчики банкетов — отметка обязательна. Ответ получателя записывается после уведомления (п. 8.9.4.1).
9. **Закрытие:** причина, меры, заключение, длительность «открыт → закрыт» → отчёт PDF. По предписанию без документа об утилизации не закрыть.
10. **Рассмотрение руководством.** После закрытия директор записывает решения и действия (п. 8.9.5, 9.3.2 e, 9.3.3). На экране — «Ждут рассмотрения руководством».
11. **Учебный отзыв** (симуляция изъятия, п. 8.9.5) — без блокировок и изменения склада. На экране — дата последнего; при заданной периодичности — «пора провести».
