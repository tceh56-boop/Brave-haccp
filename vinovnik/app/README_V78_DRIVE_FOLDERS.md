# Mon Chef V78 — папки на Google Диске: где какие документы лежат (17.11.2026)

Основание — ваше поручение: «при установке системы код создавал бы архитектуру папок, где какие документы лежат, так же как архитектура папки ttk, и html-интерфейс читал документы из папок».

## Что делает установка
Миграция (Настройки → «Миграция данных», **шаг 15**) создаёт в общей папке **«Mon Chef — Документы»** 27 разделов. Повторный запуск ничего не дублирует. То же делает кнопка **«Создать папки» / «Проверить папки»** на экране «Папки и документы на Диске».

## Куда система кладёт файлы
- Документ из «Документы предприятия» (загрузка или «создать текстом») — в папку категории: ТТК → «ТТК — документы», охрана труда → «Охрана труда», журналы → «08 Журналы», ППК → «04 ППК и ХАССП», декларации → «Сертификаты и декларации».
- Документы на сырьё → «Сертификаты и декларации»; накладные → «Накладные»; бланки банкетов → «12 Банкеты».
- PDF «Порядок отзыва», «План ХАССП», «Порядок действий при ЧС» → «04 ППК и ХАССП»; ППК, лаборатория, ТУ, отчёты, формы ОП, реквизиты, журналы, архив, пакеты, резервные копии, выгрузки, временные файлы — в свои разделы (модули берут папку из реестра).

## Что интерфейс читает из папок
- Экран **Документы → «Папки и документы на Диске»** (и Настройки): разделы, на месте ли папка, сколько файлов и подпапок, ссылка; **«Обновить список файлов»** — система обходит папки (до 3 уровней) и записывает файлы; **«Файлы»** у раздела — список с подпапкой, поиск по названию, отметка «внесён», если файл есть в реестре документов. Файлы, положенные в папку руками, видны после обновления.
- **ТТК** читаются из «01 ТТК» (или своей папки), **нормативы** — из «02 Нормативы», **фото блюд** — из «13 Фото блюд».

## Прежние папки (предприятие уже работало)
- Папки, заданные раньше (свойства модулей, ID папок ТТК, фото, бланков и накладных в коде, папки по прежним названиям), **находятся и регистрируются как есть** — файлы и ссылки не трогаются. Пустые системные папки с прежними названиями переносятся в общую папку и получают названия разделов.
- Папки с файлами вне общей папки показываются «не на своём месте». **«Разложить папки по разделам»** (директор, с подтверждением) переносит их: ID, файлы и доступ сохраняются; системные папки переименовываются, папки ТТК, фото и нормативов сохраняют свои названия.
- **«Указать свою папку»** (директор): раздел и ссылка — например, существующая папка ТТК или «Госты санпин». Папка не переносится и не переименовывается.

## Найдено и исправлено
- В сборке были постоянные ID папок ТТК, фото, бланков и накладных на Диске пилотного предприятия. На новом предприятии этих папок нет, синхронизация ТТК и фото не работала бы. Теперь ID берутся из реестра при каждом вызове; на пилоте прежние папки остаются (регистрируются как «прежняя папка»).
- Поле поиска файлов перезагружало прежний раздел при уходе фокуса и мешало открыть другой — теперь поиск идёт по уже загруженному списку, сразу при вводе.

## Права
- **Смотреть разделы и файлы:** «Документы», «ХАССП» (директор, ответственный за ХАССП); технический доступ.
- **Создать / проверить папки, обновить список файлов:** «Документы», «Резервные копии» (директор, ответственный за ХАССП); технический доступ.
- **Указать свою папку, разложить прежние папки:** «Резервные копии» (директор); технический доступ.
- **Файлы «11 Персонал»:** «Сотрудники» или «Медкнижки — просмотр» (директор, ответственный за ХАССП).
- Шеф-повару и поварам экран недоступен. Действия — в журнале аудита (FOLDERS_…).

## Ограничения
- Проверено на эмуляторе Apps Script. Перенос папок (`moveTo`) и чтение на настоящем Диске — проверить на пилоте: «Папки и документы на Диске» → «Проверить папки» → «Обновить список файлов».
- Доступ к папкам на Диске система не меняет: кому открыть «11 Персонал» и другие папки, решает владелец Диска.
- ID рабочей таблицы (`SHEET_ID`) по-прежнему задан в коде — этим шагом не менялся.
- Список файлов обновляется по кнопке, а не сам: до 400 файлов на раздел, до 3 уровней подпапок.
