## Установка в Apps Script (после этапов M1–M5)
1. В `install/Installer.gs` укажите ветку `claude/amazing-cori-nctye5` (сейчас там `claude/new-session-jd6imq`) или слейте эту ветку в ту.
2. `installTsekh` → обновить редактор.
3. `initializeDatabase()` — создаст новые листы кассы (смены, заказы, позиции, оплаты, залы, столы, модификаторы, стоп-лист…).
4. `migratePosSchema_()` — нужно, только если листы кассы уже создавались раньше: допишет новые колонки в конец.
5. `runPosTests_()` — все строки должны быть OK, включая COLUMNS_* (порядок колонок совпадает со схемой).
6. Создать сотрудников с ролями КАССИР / ОФИЦИАНТ; менеджер — «Касса и зал» → «Настройка зала», «Модификаторы».
7. QR-меню (по желанию): отдельный проект Apps Script по инструкции `qrmenu/README.md`, затем адрес …/exec — во вкладку «QR-меню».
