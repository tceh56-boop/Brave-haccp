# План тестирования модуля «Касса» (ЦЕХ)

Стенд: `replica/tests/harness.js` — все gas/*.gs в Node с имитацией Apps Script (листы, кэш с лимитом 100 КБ,
блокировки), браузерные сценарии — Chromium/Playwright c тем же сервером. Запуск всего:

    for t in replica/tests/pos_*.js replica/tests/installer_test.js; do node $t | tail -1; done
    for s in replica/tests/shots_m*.js; do node $s; done

| поток | наборы | ключевые случаи |
| --- | --- | --- |
| F01 продажа на кассе | pos_test, pos_fulfill_test, shots_m5 | права, нет смены, чужое блюдо, цена 0, версия заказа (две вкладки), сдача, нехватка, безнал больше суммы, повтор оплаты тем же operationId, списание по ТТК, нет ТТК → задача |
| F02 заказ официанта | pos_floor_test, shots_m2 | один заказ на стол, чужой стол, позиция на кухне неизменна, дозаказ, перенос, пречек и снятие, официант без оплаты/смены/выручки |
| F03 стоп-лист | pos_stoplist_test, shots_m4 | авто по годному остатку, без дублей, снятие после прихода, ручной стоп, без смены — без пересчёта |
| F04 смена | pos_test, pos_refund_report_test, pos_bugs_test | X/Z, расхождение, пустой заказ, итоги в «Экономику» (поступление/выплата) |
| F05 гость и бонусы | pos_loyalty_test, shots_m6 | согласие на ПД, маска телефона, лимит списания, скидка в SALES, возврат с пересчётом, баланс = проводки, обезличивание |
| модификаторы | pos_modifiers_test, shots_m3 | мин/макс, чужой модификатор, цена, объединение строк, списание продукта добавки |
| возвраты и отчёты | pos_refund_report_test, shots_m5 | частичный/полный, лимит безнала, сторно, отчёт по сотрудникам, миграция колонок |
| чаевые | pos_tips_test, shots_m7 | https-only, своя/чужая ссылка, QR в заказе и на пречеке |

| устойчивость | pos_bugs_test | большие листы > 100 КБ кэша, заказ с собой на кухню, пустой заказ |
| дашборд руководителя (этап 20) | reports_dashboard_test, shots_reports | права, «сегодня» по серверу, выручка со сторно, блок кассы, сбой раздела не роняет дашборд, каталог 20 отчётов |
| заготовки (M9) | prep_test, shots_prep | права, прогноз по дню недели и по среднему, просрочка не в остатке, нехватка сырья без списания, партия и маркировка, пропуск |
| установка | installer_test | закрытый репозиторий: токен, ошибка без токена, только gas/ |

Не автоматизировано (вручную после установки): реальный Apps Script (квоты, время ответа), печать на принтер чеков,
распознавание настоящей накладной, QR-коды quickchart.io, работа на планшете кассира.
